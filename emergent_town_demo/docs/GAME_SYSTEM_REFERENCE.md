# 廷根涌现式剧情模拟器：系统设定一览

本文档面向策划、程序和展示人员，汇总当前代码中已经实现的世界设定。它描述的是“现状”，不是未来概念稿。

## 1. 项目目标

世界模拟器先依据人物状态、欲望、关系、情报、阵营和长期计划产生事件，再让 LLM 在合法行为范围内负责选择与组合。LLM 不直接改写世界状态，最终结果由规则和判定系统结算。

主要矛盾是廷根官方非凡者与邪恶组织、失控者及危险野生非凡者之间的长期对抗。普通人的工作、目击、传播、求助和受害经历构成冲突的社会涟漪。

## 2. 时间与角色层级

一周按星期一至星期日循环。每天分为：`morning`、`afternoon`、`evening`、`late_night`。

默认生成 200 名 NPC，显示名称为 `1` 至 `200`。其中 180 名普通人、20 名非凡者；当前主线初始化后的构成为 7 名官方、7 名野生、6 名敌对非凡者。

普通人不调用 LLM。他们按照个人 `work_days` 和 `work_phases` 固定上班或上学；每人的休息日和班次并不完全相同。工作行动会显示“职业（隶属：工作地点）”。医院、疯人院、酒馆、餐厅、歌剧院、码头和工厂包含轮班或晚班。非凡者保留表面职业与班表，但可以调用 LLM，根据案件、仪式、情报和长期目标改变行动。

角色层级：

| 标识 | 含义 |
|---|---|
| `ordinary` | 普通人 |
| `official_beyonder` | 官方非凡者，主要为值夜者 |
| `wild_beyonder` | 未加入官方的野生非凡者 |
| `hostile_beyonder` | 邪恶组织成员或敌对非凡者 |

角色处置状态包括：`active`（活跃）、`wanted`（在逃嫌疑人）、`dead`（死亡）、`missing`（失踪）、`arrested`（被捕）、`fled`（已逃离廷根）。

## 4. 非凡途径与序列

廷根是小城市，当前只生成序列 9、8、7；数字越小，等级越高，相关判定加成越大。

- 官方常见途径：不眠者、收尸人、阅读者。
- 野生常见途径：占卜家、学徒、怪物、猎人。
- 敌对常见途径：罪犯、囚犯、秘祈人。

## 6. 场景

当前地图和剧情共使用 21 个场景。主要公共/职业地点为：黑荆棘安保公司、黑夜女神教堂、市场、酒馆、医院、码头、工厂、大学、报社、占卜俱乐部、银行、侦探会所、歌剧院、疯人院、餐厅。住宅区用于居住；警察局、三号仓库、地下市场、查尼斯门地下区域和红月亮街暂作为剧情或特殊功能地点保留。

## 7. NPC 数值与属性

### 核心资源

- `health`：健康
- `sanity`：理智
- `wealth`：财富

### 生理与社会状态

- `energy` 精力、`satiety` 饱腹、`pain` 疼痛
- `stress` 压力、`fear` 恐惧、`alertness` 警觉、`morale` 士气
- `loneliness` 孤独、`reputation` 声望、`legal_risk` 法律风险
- `social_support` 社会支持、`civic_duty` 公民责任感

### 基础需求与情绪

- 需求：`hunger`、`fatigue`、`financial_pressure`
- 情绪：`anger`、`anxiety`、`happiness`、`fear`

### 性格

`curiosity` 好奇、`risk` 冒险倾向、`social` 社交倾向、`morality` 道德、`ambition` 野心。

### 通用能力

`knowledge`、`inspiration`、`dexterity`、`strength`、`luck`、`charm`。

### 专项技能

`observation` 观察、`tracking` 追踪、`stealth` 潜行、`counter_tracking` 反追踪、`investigation` 调查、`deception` 欺骗、`insight` 洞察、`combat` 战斗、`ritual` 仪式、`mysticism` 神秘学、`willpower` 意志。

低精力、饥饿、贫困、高压力、高恐惧等状态会提高休息、进食、求助、赚钱甚至非法获利的欲望权重，并压低不合适行动的权重。

每个时间段精力下降 3、饱食度下降 4，工作和危险行动另有精力成本。每日结算时压力、恐惧、疼痛、警觉和法律风险会缓慢回落；孤独随时间增加，社交后降低；经济压力按当前财富重新计算。士气和公民责任感会缓慢回归中间水平，避免长期运行后大量数值永久卡在 0 或 100。`hunger=100-satiety`、`fatigue=100-energy`，它们只是界面和欲望层的反向指标。

## 8. 人际关系

每对角色可维护：`trust` 信任、`affection` 好感、`suspicion` 怀疑、`fear` 畏惧。交流、撒谎、援助、目击犯罪、调查和冲突会改变关系；关系又会影响是否分享情报、求助、包庇或举报。

关系还带有可修改的双向类型：朋友、仇人、同事、前同事、爱人。初始化时会按工作地点建立同事网，再叠加朋友、仇人、爱人和前同事关系；同一种关系会同时存在于双方记录中，但双方后续的信任、怀疑等数值仍可因各自经历产生差异。

休息使用每个 NPC 独立的 `home_scene`。私人住所不触发公共场景随机事件，也不会让其他正在家中休息的 NPC 与其自动互动。

共同活动使用邀请系统：邀请者和被邀请者必须互相具有活动要求的关系，双方在同一时段都必须有自由计划。系统先计算接受或拒绝，再在接受后同时把双方计划改成 `MEET_PERSON`。爱人可以约会，朋友可以结伴娱乐，同事和前同事可以聚会或叙旧。LLM 直接生成的会面不会绕过邀请校验。

## 9. 欲望系统

当前欲望包括：恢复精力、解决饥饿、寻求治疗、维持理智、缓解压力、寻找陪伴、获取金钱、维护声望、避免被捕、履行职责、寻求社会援助、非法获取金钱、保护廷根、保护阵营、隐藏身份。

欲望由状态和身份计算优先级，再用于筛选行为。它们不是直接事件文本。

## 10. 行为库

### 职业与序列特殊需求

部分身份拥有会每日下降、通过对应行动恢复的特殊需求：

| 身份 | 消耗条 | 低值时可触发的行动 |
|---|---|---|
| 罪犯途径 | `crime_control` 自制力 | 入室盗窃、扒窃、暴力勒索 |
| 秘祈人 | `ritual_stability` 仪式稳定度 | 合法受监管仪式或非法秘密仪式 |
| 非凡者 | `occult_supply` 非凡资源储备 | 寻找非凡材料、文献或物品 |

这些数值采用“剩余量”语义，每天随时间下降，越低越急迫；成功满足需求后回升。警察和值夜者没有“破案欲望条”。巡逻、接警、调查与仪式干预属于职业职责，在其排班的工作时段固定执行；有已分配案件时优先处理案件，没有案件时才进行巡逻。

犯罪者在重伤或法律风险很高时，犯罪自制力下降速度会减半，避免角色在逃亡或濒死期间仍机械地按固定周期犯罪。寻找非凡材料失败不再恢复 `occult_supply`，只有实际取得物品才会补充资源。

被捕、失踪、已经逃离廷根或健康不高于30的角色会暂停特殊需求下降；他们不会因为关押或住院数日而在恢复行动的一刻立刻犯罪或举行仪式。长期行动的负责人处于这些状态时，计划保留当前阶段但停止结算，直到负责人恢复行动或计划被其他角色正式接管。

犯罪成功会转移财物，暴力犯罪还会伤害受害者；无论成功与否都可能留下物证。犯罪失败会增加法律风险并直接形成案件。警察和值夜者巡逻时可以发现犯罪或灵性痕迹，并据此建立案件和嫌疑人。非法仪式会留下灵性残留、提高法律风险，失败时还可能损失理智。找到的非凡材料会成为真实的 `WorldObject`，可继续用于交易、仪式或藏匿。

### 袭击、报警与警察处置链

暴力袭击会结算具体伤害；受害者可能受伤，也可能因健康降至零而死亡。健康 `31～60` 会造成检定减值并优先治疗，`16～30` 会取消工作、巡逻、追踪和战斗，`1～15` 只能休息、求助或接受治疗。受伤会增加疼痛和恐惧；危重伤如果跨日仍未治疗，可能恶化死亡。医院会同时恢复健康、降低疼痛与压力。

报警不是一句摘要，而是结构化 `IncidentReport`，保存报警人、原始事件、事发日期与时段、完整地点、完整经过、受害者、嫌疑人和目击者。嫌疑人不能成为自己案件的报警人。一次原始事件只建立一份主报警，其他目击者和亲友的陈述以补充证词并入，不再重复出警。

警察接报后，报警状态从 `draft` 变为 `assigned`，案件会分配具体警员，并给该警员生成高优先级 `HANDLE_INCIDENT_REPORT` 行动。警员随后前往原始事发地点，确认伤亡、救助伤者、收集痕迹并记录嫌疑人。凶案同时具备嫌疑人与物证后会进入 `arrest_authorized`；警员在工作时段执行逮捕检定，结果为抓捕归案或逃脱并转为在逃嫌疑人。完整报警表会写入世界快照的 `incident_reports` 字段。

夜间精神异常不再随机生成一条“SAN 下降”文本。低理智角色会被互为朋友或爱人的 NPC 探望和劝医；公共地点的灵性异常必须同时有当事人和目击者，并继续生成救助、调查、官方响应或敌方掩盖行动。

### 生存、工作与社交

- 正常工作、寻找临时工作、短暂休息、购物
- 请求援助、寻求帮助、祈祷、社交、与指定人物会面

### 情报交流

- 分享情报、对情报撒谎、向警方报告
- 交流会转移具体情报事实，并记录来源、可信度和知情者，而不只是生成“交谈了”的文本

### 调查与执法

- 观察现场、搜索现场、询问证人、查阅记录
- 监视地点、调查地点、监视嫌疑人、追踪目标
- 警方调查、检查神秘痕迹、规划干预、阻止仪式、响应神秘事件

### 犯罪、隐匿与反制

- 偷窃物品、隐藏/转移/销毁证据、逃往其他场景
- 警告同伙、反调查、反追踪、举行秘密仪式

部分行为仍是通用注册项，已有统一名称和接口，但具体效果深度不完全一致；后续应逐项补齐前置条件、成本、痕迹、关系变化和失败后果。

## 11. 物品、证据与情报

物品具有持有者或所在场景，可被购买、偷窃、藏匿、转移、发现或销毁。证据不是纯文本：`TraceEvidence` 会记录种类、来源行动、场景、强度、隐藏程度和关联计划。

情报使用 `IntelFact` 表示，包含事实内容、来源、可信度、知情者和关联对象。这样“目击—转述—报警—调查—确认”可以形成可追踪的信息链。

## 12. 长期计划与故事链

长期计划由目标、阶段、计划行动和后续计划组成。当前非法仪式主链为：

1. 选择目标
2. 收集仪式材料
3. 准备场地
4. 举行秘密仪式
5. 清理痕迹或逃亡

官方可以通过痕迹发现案件，调查、追踪并规划干预。计划完成或失败后可产生死亡、被捕、失踪、逃亡、污染场景、新角色介入等世界后果，并衍生追捕仪式首领、净化现场、回收仪式成果、营救被捕成员、再次阻止仪式等后续链条。

营救被捕成员成功后不会结束主线：获救者与营救者会转入地下市场重建隐秘支部，自动创建下一次非法仪式行动；官方同时创建追捕获救者的长期目标。新计划与追捕计划并行推进，哪一方先完成由各阶段检定决定。

第一次营救后的目标是建立新的隐秘安全屋；发生重复营救后，敌对组织会升级为“利用仪式伏击官方追捕者”，目标从被动恢复转为主动反击，避免无限重复同一场地、同一目的的仪式循环。

市场食物、医院药品和教会救济餐会在每日结算时由本地生产系统补货，并有库存上限。按200人口规模，默认每日补充70份市场食物、8份医院药品和4份教会救济餐，分别限制在240、60和80份。

如果夜间灵性异常中的救助者与被救者分属官方和敌对阵营，系统会同时提高信任与怀疑，创建只有双方知道的“跨阵营救命人情”情报，并保留为后续交流、包庇、审讯或背叛的因果锚点。

## 13. 判定规则

行动采用 d100 思路：骰点加能力、技能、序列差、环境、证据和关系等修正后与难度比较。结果按差值分级：

| 差值 | 结果 |
|---|---|
| `>= 40` | 完全成功 |
| `>= 15` | 成功 |
| `-14 ~ 14` | 部分成功 |
| `-39 ~ -15` | 失败 |
| `< -40` | 严重失败 |

追踪与反追踪都应在日志中输出骰点、相关技能、序列修正、环境修正、总值和结果，便于复盘。

## 14. LLM 的职责边界

只有非凡者会进入 DeepSeek/Ollama 候选。模型可根据其当前欲望、已知情报和合法行为候选选择或组合行动。普通人的日常班表完全由规则系统产生。规则层负责验证前置条件、目标存在性、地点、资源成本、骰点、状态修改、痕迹和后果。接口失败时可退回规则策略，不应中断模拟。

完整的默认 200 人安排见 [NPC_ROSTER.csv](NPC_ROSTER.csv)，可用 Excel 打开。该表列出代号、层级、职业、隶属地点、工作日、班次、途径和序列。

## 15. 当前开发重点

1. 将仍留在 `town_demo.py` 的世界初始化和结算逻辑继续拆入包内模块。
2. 扩充行为效果，而不只是扩充行为名称。
3. 为 Godot 输出稳定的世界快照、事件流、角色可见状态和玩家可选指令。
4. 区分“模拟内部完整数据”与“角色/玩家当前可知信息”。
5. 增加长期运行指标：计划完成率、冲突爆发率、情报传播深度、因果链长度和角色处置数量。

代码中的枚举、默认值和注册表仍是最终依据；修改实现后应同步更新本文档。

运行目录中的 `trace.jsonl` 是完整调试轨迹；`game_events.jsonl` 是面向 Godot 的精简事件流，只保留犯罪、伤亡、报警处置、案件推进、非凡冲突和长期计划后果等可表现事件。界面层应优先消费后者，避免把移动、状态微调和记忆写入等内部事件直接展示给玩家。

# LLM 输入精简与费用控制（2026-09-10）

## 本轮范围

暂停后续校园功能扩展，先降低每次请求的冗余输入。保留基础 20 名深度 NPC、额外觉醒好友、每晚完整规划及玩家随时聊天；没有新增每日聊天次数限制，也没有把 NPC 决策改回规则替选。

此次没有调用付费 API。以下是离线传输与回归验证，不是模型效果或账单节省比例的实测。

## 已实施

1. 精简决策、每日规划、对话提示词，保留身份约束、个人选择、合法候选、同地社交组合、采购自选、失败反馈及防止伪造事实的要求。
2. 精简共用的 13 类行动规则，仍向模型解释可行条件，而不是规定 NPC 必须怎么做；人格量表、本人预算、已确认约定没有删减。
3. 仅在实际发送给模型时，把同组候选中完全相同的解释、参数、费用及复核条件提取到 `option_defaults`。不同值、缺失值、目标、地点、候选 ID、价格上限等保持原样。压缩收益不足以抵消格式说明开销时，不使用该格式。
4. 要求决策理由简短（40 汉字以内）；不缩小原有 JSON 输出 Token 上限，以免截断计划而触发失败。对话原有 160 汉字要求不变。
5. OpenAI-compatible 与 Ollama 使用同一发送格式。没有引入专属于某服务商的新参数，官方 DeepSeek 的既有 thinking 配置不变。

内部请求、行动校验、原子结算、任务锁、行动次数、缓存与用量计数逻辑未改。传输格式精简不授权执行任何新行动。没有裁剪人物性格、个人记忆、关系或合法候选数量。

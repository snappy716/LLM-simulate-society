# LLM 运行时修正与真实验收

日期：2026-09-08。仅在 `codex/campus-demo-architecture` 交付，不合并 main，不进入主线或第 9～12 步。本次是既有第 8 步后的 LLM 能力修正，不代表整个 Demo 已完成。

## 本次修改

1. **真实接口与可观测性**：通用兼容接口新增思考模式和请求超时；自动模式仅适配官方 DeepSeek V4，其他服务默认不增私有参数。Godot 面板区分配置已应用与真实响应成功，显示截断/鉴权等安全错误码；失败响应可取得的实际 Token 仍入账。客户端和过夜等待使用实际配置的超时。个人密钥未写入仓库或测试产物。
2. **身份与对话**：中心化绑定本人和当前对方，允许模型依据本人已完成的公开日常活动回应；不自动透露夜相活动或对方私事。长句原样复读会回退规则且不自动重试。此处不能保证消除一切语义幻觉。
3. **社交意图落地**：在同一次过夜规划中，深度 NPC 可选择一项有目标、时段和地点的社交/合作意图。提供匹配活动编号，严格校验组合。日内按实际位置、忙碌、冷却及接受规则执行并保存回执。失败不会传送、强制同意或触发日内模型重规划。玩家询问安排时，在 NPC 愿意且关系允许的前提下得到有限披露。

基础 20 人与额外好友规则不变；玩家现场/手机聊天仍随时可调用，无每日次数上限。自动规则交流仍存在；自动模型措辞只在跨日结算中发生，日内没有新的后台模型决策请求。

## 最终真实三日结果

公开服务 `https://api.deepseek.com`，模型 `deepseek-v4-flash`。种子 42，200 NPC，其中基础 20 人接模型；连续模拟第 2～4 天，过程中玩家不介入。真实模型与离线对照使用同种子；测试不是多个随机种子的统计实验。最终测试使用已交付的生产非思考选项，没有测试层 HTTP 请求体改写。

| 指标 | 最终实测 |
| --- | --- |
| 模型完整日程 | 60/60 通过，240 个时段选择 |
| 实际模型调用 | 70 次：60 规划、7 自动交流措辞、2 玩家对话、1 连通探针 |
| API Token | 输入 144,681；输出 8,228；合计 152,909 |

| 最终提供方错误 / 响应拒绝 / 预算拦截 | 0 / 0 / 0 |
| NPC 完成论坛任务 | 67 项；离线对照 70 项 |
| 互动衍生来源的已完成任务 | 5 项；离线对照 4 项 |

240 个深度人物时段均有活动完成，其中 210 个活动/地点与计划相同。30 个被执行层覆盖：19 次必要物品短缺、10 次已接受论坛任务、1 次未细分原因；不能将“计划通过”说成“计划全部照做”。41/240 个原始选择不是规则第一候选；这只是选项差异，不能直接当成故事质量。

最终玩家对话样本：深度 NPC 回应“你好，我最近刚休息了一下，感觉还行。你呢？”，普通 NPC 回应“还行吧，刚在宿舍休息了一会儿。你呢，最近忙不忙？”。不再复述输入问题，但只有两份样本，尚不足以证明长期人格一致性。

最终 Godot → HTTP 桥 → 生产认知接口 → DeepSeek 实测：20/20 人日程接受，22 次调用，输入 46,039 / 输出 2,855 Token（合计 48,894），无错误/拒绝/回退；过夜转场与次日上午切换通过，日内再过时段不产生新模型请求。日志标记 `CAMPUS_LIVE_API_FLOW_OK`。

上述两项最终验收合计 92 次请求、201,803 Token，**不包含此前基线、排查及中间调试的消耗**；实际金额需以服务商账单为准，不把 Token 数直接冒充费用。

## 与基线的区别及仍有的不足

历史基线详见 `DEEPSEEK_LIVE_ACCEPTANCE_20260908.md`，当时三日仅 2 次实际社交意图由模型选择；本次最终为 16 次。先前一次中间修正版达到 18 次但有 4 份日程因社交地点与活动不匹配被拒绝；随后补充匹配活动编号，最终轮次 60/60 通过。没有放宽空间或响应校验，也不能因最后一次无拒绝就保证今后永不失败。

世界在没有玩家操作时确实继续生活、接单、交流、战斗和结算，但多数仍由规则系统保障；本轮任务数未高于离线对照。社交计划的实际碰面率只有 16/35，说明目标日程预测与任务改道仍限制兑现。后续可在本次验收之后讨论双方约定协调和长期故事质量评估，不在本次擅自扩大范围。

真实过夜等待仍取决于网络、串行请求和候选上下文，并未宣称消除过夜等待。日内不重规划解决的是日内反复调用问题。用量不设硬配额不等于调用免费；测试保持有限天数，失败保护不会自动无限重试。

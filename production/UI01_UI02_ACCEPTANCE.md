# UI01 公共规范与 UI02 开始/系统菜单验收

2026-09-11。基线为 `2ba4cfb`。只推进用户指定的 UI01、UI02，不推进主线，不修改既有 NPC 决策规则或美术场景。

## 已实现内容

- 项目主场景改为 `campus_title.tscn`，稳定的项目存储名称保持不变，不丢失既有 user:// 配置与存档路径。
- 标题提供继续、新游戏、读取存档、设置、退出；没有可继续进度时禁用并说明原因。
- “继续”优先恢复本次会话；冷启动时按文件写入时间选择最近的兼容当前存档。备份仍需玩家在读取页面明确选择。
- 新游戏展示当前 Demo 支持的预设规则，确认后通过 `/kernel/saves` 的 `new` 操作重建第一天校园。构建、校验在替换前完成，revision 单调递增；不删除已有存档、不更改配置中的模型、不调用付费生成接口。
- 首次新游戏显示操作引导；探索时 Esc 打开暂停菜单，能恢复游戏、存读档、看说明、进入设置、返回标题或退出。
- 返回标题保留本次会话，退出前明确提示未保存进度会丢失；新游戏、返回标题、退出、存读档均有确认。确认默认取消，避免误按 Enter。
- 标题读取页不能保存启动时的临时世界。存档展示日期、时段、地点、内容版本与兼容性初检；没有实际游玩时长数据，不编造时长。
- 复用既有三个槽、备份、令牌/revision 校验、地图安全落点和 API 设置。初检兼容不是跳过加载时的完整权威校验。
- 公共主题、主次/危险操作、搜索/筛选/分页/页签、状态提示、滚动与确认组件已建立。规范见 `design/UI01_PUBLIC_SPEC.md`；不宣称所有业务页已完成专项重排。

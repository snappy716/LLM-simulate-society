## 交付内容

真实表世界对质未缓和后形成持续案件；询问双方、联系方式/同地验证、重新检查意愿、调解缓和/拒绝/和解、每日社会冷却、无资源奖励、存档与私人日志。NPC 可以通过已有共同联系人发送求助，并复用相同处理器完成调解。人物面板有可操作按钮和实际结果反馈，已有手机联系人收到记录。

过夜模型只得到自己参与的未解决纠纷摘要。此批不新增实时自动思考，不限制玩家 LLM 对话次数；全部本批验收 API 调用为 0。没有把心理支持设定为保证成功的治疗法。

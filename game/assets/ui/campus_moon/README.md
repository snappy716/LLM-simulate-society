# 校园月相 HUD 图标

按用户确认的极简功能轮廓，为本项目重新绘制的 SVG；并非截取参考游戏资产。
64 × 64 透明源画布，冰白 `#dff5ff`、亮蓝 `#1888ff`、深蓝负形 `#123462` 为三个语义色区。
手机空屏；仅卡牌、关系保留月相元素。当前显示 30 px，热区 46 px，不随图形一起缩小到难以点击。
六枚分别用于手机、地图、队友、人物与物品、卡牌库、关系；无外框和背景底座。

2026-09-11 场景融合迭代：`scene_ink.gdshader` 将源色区映射为低饱和雾蓝/浅灰蓝，加入轻微透明度与轮廓下方的柔阴影；悬停/键盘焦点用 0.16 秒渐亮回到明亮蓝色。不改变原图标轮廓。材质按实例独立，避免悬停一枚时其他入口一起变色。无屏幕采样、实时模糊、全屏着色或额外后处理缓冲。源 SVG 继续保留，方便后续定制替换。

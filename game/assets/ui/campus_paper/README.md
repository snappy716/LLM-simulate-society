## 资源与运行

- 原创项目内 SVG，不调用 imagegen；适用于小尺寸、透明背景和后续直接编辑。
- 每枚 64×64，源色：纸白 #dff5ff、蓝 #1888ff、深蓝 #123462。
- 继续使用原 scene_ink 着色器：源色被映射为不透明亮白、清亮蓝与深色负形；约 1px 暗边处理复杂/浅色背景，不增加底框。
- 仍为 30px 图形上限、46px 点击区域、0.16 秒悬停/焦点反馈；布局、入口、手机通知规则不变。
- 原文件 campus_moon/*.svg 保留。campus_hud.gd 的六个 preload 路径切换至本目录；不改变业务接口。
- 不使用外部字体、照片或嵌入位图；不新增地图、玩法或 LLM 调用。
- 测试证据与实际截图见 [验收记录](../../../../production/UI_PAPER_ICONS_ACCEPTANCE.md)。

## 后续扩展约束

确认这六枚方向后，手机应用采用同源物件语言，允许略多的叠放与折角。返回、关闭、搜索等辅助图形仍可用线条；学院采用学科标识，社团采用活动物件，不能全部变成证件或书本。辨识优先，不为“统一”而给每枚加同一装饰。

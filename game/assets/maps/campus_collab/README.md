# 校园协作美术目录

来源：美术协作者提供的 `Project-c-0.1(1).rar`，基线更新日期为 2026-09-05。

本目录只接入新版压缩包的七张地图。运行时目录位于
`res://data/campus_art_catalog.json`，玩家可在校园联调场景按 `M` 打开地图面板；选择其他区域时
会通过 Python 权威地点图校验路线。

- `campus_gate.png`：校门/教学楼与右侧道路；
- `psychology_bridge.png`：心理学院与天桥；
- `east_dormitory.png`：东区宿舍候选；
- `west_dormitory.png`：西区宿舍候选；
- `living_area.png`：食堂、商店与生活区。
- `library.png`：图书馆 V3 外部广场；
- `sports_field.png`：运动场 V2。

七图逐文件 SHA-256 已与新交付核对，原五图相同，只新增两张。历史废案不进入运行资源；新版缓存中的旧图名称不视为交付。旧包和 Git 历史不删除。

这 7 张图片现阶段仅用于开发联调。压缩包中没有地图图片的授权、源文件、生成过程或可再分发说明，画面中也包含真实校名和现实品牌近似元素。正式公开演示或发布前必须由项目负责人补齐来源与许可记录，并将校名、桥名、商店招牌等替换为本项目虚构设定。

角色动画没有从本压缩包重复导入；仓库当前的 `ModularCharacter` 已覆盖协作包的人物分层展示能力，
并继续受角色素材目录 `READ ME.txt` 的原始许可约束。

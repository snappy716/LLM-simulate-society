# 校园协作美术目录

来源：美术协作者提供的 `Project-c-0.1.rar`，接收日期为 2026-09-03。

`all_maps/` 已完整接入压缩包中的 20 张校园区域 PNG，包括校门、教学楼与校园桥、生活区、
东/西宿舍和庭院的全部迭代版本。运行时目录位于 `res://data/campus_art_catalog.json`，玩家可在
校园联调场景按 `M` 打开地图面板浏览全部 20 张图；选择其他语义区域时会通过 Python 权威地点图
校验路线，选择同一区域的迭代稿则只切换表现图。

目录根部的五张重命名图片是首次联调时选出的稳定别名，继续保留以兼容已有场景和历史提交：

- `campus_gate.png`：校门/教学楼与右侧道路；
- `psychology_bridge.png`：心理学院与天桥；
- `east_dormitory.png`：东区宿舍候选；
- `west_dormitory.png`：西区宿舍候选；
- `living_area.png`：食堂、商店与生活区。

这些图片现阶段仅用于开发联调。压缩包中没有地图图片的授权、源文件、生成过程或可再分发说明，画面中也包含真实校名和现实品牌近似元素。正式公开演示或发布前必须由项目负责人补齐来源与许可记录，并将校名、桥名、商店招牌等替换为本项目虚构设定。

角色动画没有从本压缩包重复导入；仓库当前的 `ModularCharacter` 已覆盖协作包的人物分层展示能力，
并继续受角色素材目录 `READ ME.txt` 的原始许可约束。

# NPC 认知与 LLM 运行时：基础 20 人＋额外好友

2026-09-08 更新。本页替代此前“20 个动态名额、其中 6 个觉醒名额、默认硬请求配额”的设计。

## 已实现边界

新校园内核现在把客观事实、NPC 主观认知和玩家可见记录分为三个聚合。已提交事件仍是唯一权威事实；人物年表只负责客观历史；认知层只保存某名 NPC 当时能够亲历或目击的观察、由观察形成的有限主观记忆以及阶段性反思。LLM 请求只读取后两者，不读取完整人物年表、隐藏任务状态或世界真相。

200 名持久 NPC 始终由规则执行器维持日程、移动、任务和活动。新游戏生成并保存基础 20 名深度 NPC；玩家额外接入的好友不占这 20 个名额，没有原来的 6 人上限。好友接入不会挤掉基础人物，也不会因为关系后来下降而删除长期记忆或自动撤销接入；人物仍可以拒绝玩家的请求。

接入条件使用 NPC 对玩家的关系：亲近度 ≥ 45、信任 ≥ 45、冲突 ≤ 40，由玩家在人物面板主动确认。不消耗主要行动，不自动接入所有联系人，不因一次聊天而永久接入。基础深度 NPC 不重复计数。关系条件只控制额外长期认知，不控制玩家能否临时使用模型聊天。

只要接口可用，玩家可以随时与现场 NPC 或已有手机联系人进行 LLM 对话，包括普通 NPC；仍遵守见面/联系人等空间与联系方式条件。对话不消耗主要行动，不设每日或时段调用次数上限。

## 决策管线

每个 NPC 的行动仍经过同一管线：

1. 深夜进入次日时，地点、开放时间、访问权限、路径、容量、时段和活动定义先生成合法候选。
2. 性格、需求、关系、职责、习惯、成本和风险为候选评分，每个时段最多提供 5 个合法选项。
3. 普通 NPC 采用各时段规则首选；基础 20 人及额外好友各有一次完整日程规划机会，不因调用配额只剩少数人能请求。
4. 每位深度 NPC 的一次请求包含四个时段的选项、有限主观记忆、自身资源、已知关系、目标和约定。模型分别为上午、下午、晚间、深夜选一个 ID，可以混合偏好，不再只从三套预打包日程中选一套。
5. NPC ID、世界修订号、四个完整时段及每个时段的候选 ID 必须全部匹配，才接受整份计划。不能串用其他时段 ID，不能改写参数、地点、物品或行动结果。
6. 日内执行既定安排，不再次完整推理。新任务、紧急需要、路径、库存、主要行动与受保护职责仍由规则实时核验；意图不代表未来必定成功。当天新增好友从下一次跨日参与完整规划，不偷偷重算当天日程。
7. 空响应、非法选择、错误目标、超时、HTTP 或 JSON 错误回退规则安排；不无限重试。对话和记忆内容不作为修改系统规则的指令。

任务承诺仍高于自由偏好：已经接下并到执行时间的任务由任务系统接管，LLM 不可放弃、篡改或伪造完成结果。活动成功与状态变化仍由权威处理器结算。

## 额度策略

当前游戏默认 `enforce_automated_budgets=false`，后台不再因每日次数、时段次数、用途次数或每日 Token 配额回退规则。旧数字只保留给显式开启预算的测试/诊断策略，不是玩家当前的限制；公开状态中配额显示为 `null`。

仍保留工程保护：单请求超时 8 秒、同步执行并发 1、候选与记忆长度控制、重复命令保护、模型错误回退和用量记录。普通选择/短对话默认输出上限 160 Token，四时段规划至少 512 Token，避免四个选择被截断。单次输出长度限制不同于调用次数限制。

自动 NPC 互动仍遵守游戏中的相遇条件、行动安排和同对 NPC 一时段冷却，不因请求不限量而每帧生成聊天。日内没有后台完整 LLM 重规划；玩家主动对话始终可请求。规则模式与自动回归默认不开外网。

调用计数、Token 估算、服务返回的实际 Token、缓存命中、拒绝响应、接口错误和预算拦截会进入可序列化账本。API Key 和 Base URL 只存在于本机接口对象，不进入世界状态、存档、事件、人物日志或 Git。公开快照只返回经过清理的提供方状态与额度统计，不返回 NPC 私有记忆。

## 模型配置边界

仓库只提供通用的离线规则、OpenAI 兼容接口和本地 Ollama 适配能力，不提交开发者个人模型名称、服务地址或 API Key。Godot 界面统一使用 `openai_compatible` 类型；旧版 `deepseek` 和 `deepseek_compatible` 配置仍可读取并会迁移为通用类型。每位开发者可以在自己的 Godot 本地接口面板中建立不同配置；这些配置由 `.gitignore` 排除，不会随分支共享。

常规 NPC 时段选择应使用低成本模型；高质量对话或推理模型只留给后续重要对话、日终反思和剧情节点，不应用于 200 人每时段常规决策。

## 本地配置与待补前置条件

Godot 中按 Esc 打开接口面板，选择“兼容接口”，填写仅属于当前开发者的 Base URL、模型名和 API Key 后应用。配置文件位于 `user://llm_interfaces.cfg`，已被 Git 忽略，但它本身不是系统钥匙串且没有加密；共享电脑不应留存正式密钥。

历史版本曾完成个人接口联网冒烟测试，不代表当前 Key 仍有效，也不代表本轮新增日程输出协议已在真实模型上验收。本轮自动回归使用假提供方和离线规则，不消耗正式额度。个人 Base URL、模型名和 API Key 均不提交。

## 验收结果

自动测试覆盖基础 20 人保留、7 名及更多额外好友、关系阈值、普通 NPC 连续对话、四时段组合、非法组合回退、21 名深度人物均获得跨日规划、旧档迁移、用量账本和私有数据隔离。Godot 测试用明确标识的关系/假模型夹具，通过真实按钮、命令与过夜接口验证；后台无窗口运行。

存档认知版本升级为 2。已知旧内容版本经精确 manifest 白名单迁移，保留原有觉醒者、记忆、当日日程、资源、事件和 RNG，不修改原档文件。旧档缺少独立基础名单时保留旧深度名单中的非觉醒者，再补足基础 20 人；不要求旧觉醒者重新满足关系阈值。

## 尚不能宣称完成的目标

更多模型参与和日程组合只是提高自由度的基础，不能用请求次数证明故事“极其多样”。目前模型仍在已实现行动空间内选择，不能任意创造新行动类型或直接生成已完成任务；对话中的新承诺须通过现有提议/接受/执行机制落地。下一轮真实模型测试应检查性格与记忆一致性、选择差异、约定兑现、任务接力和多日后果，而不是只评价台词流畅程度。

# NPC 认知与受限 LLM 决策运行时

## 已实现边界

新校园内核现在把客观事实、NPC 主观认知和玩家可见记录分为三个聚合。已提交事件仍是唯一权威事实；人物年表只负责客观历史；认知层只保存某名 NPC 当时能够亲历或目击的观察、由观察形成的有限主观记忆以及阶段性反思。LLM 请求只读取后两者，不读取完整人物年表、隐藏任务状态或世界真相。

200 名持久 NPC 始终由规则系统维持日程、移动、任务和活动。系统每个时段重新计算 20 个深度认知槽位，优先考虑玩家永久觉醒的人、当前队友、已接任务者、夜相相关性、与玩家关系和明显情绪压力。退出槽位不会删除 NPC，也不会丢失权威状态。玩家可在人物概况中永久觉醒最多 6 名 NPC，这 6 人始终占据深度槽位。

## 决策管线

每个 NPC 的行动仍经过同一管线：

1. 地点、开放时间、访问权限、路径、容量、时段和活动定义先生成合法候选。
2. 性格、需求、关系、职责、习惯、成本和风险为全部候选评分。
3. 普通 NPC 直接采用规则最高分。
4. 深度 NPC 在接口已配置且仍有预算时，只收到排名前 5 的合法候选、有限主观记忆与自身状态。
5. LLM 只能返回一个候选 ID 和角色内理由。
6. NPC ID、世界修订号和候选 ID 通过严格校验后，规则执行器才接受选择。
7. 空响应、越界动作、错误目标、超时、HTTP 错误、JSON 错误或预算不足都立即回退规则首选，不阻塞 200 人世界推进。

任务承诺仍高于自由偏好：已经接下并到执行时间的任务由任务系统接管，LLM 不可放弃、篡改或伪造完成结果。活动成功与状态变化仍由权威处理器结算。

## 额度策略

第一版采用偏保守的硬限制：

- 每时段最多 4 次外部请求；
- 每游戏日最多 12 次外部请求；
- 每游戏日最多预估 24000 Token；
- 单次最多生成 160 Token；
- 同步运行时同时最多 1 个请求；
- 超时 8 秒；
- 相同上下文使用本地决策缓存，最多保留 96 项；
- 只有当前 20 个槽位中的 NPC 才可能请求，且规则模式默认不开外网。

调用计数、Token 估算、服务返回的实际 Token、缓存命中、拒绝响应、接口错误和预算拦截会进入可序列化账本。API Key 和 Base URL 只存在于本机接口对象，不进入世界状态、存档、事件、人物日志或 Git。公开快照只返回经过清理的提供方状态与额度统计，不返回 NPC 私有记忆。

## 模型预设

模型目录已按提供的名称登记：

| 用途 | 环境变量名 | 模型名 |
| --- | --- | --- |
| 高质量对话 | `V4pro_CHAT_MODEL` | `stocklink-chat` |
| 深度反思 | `V4pro_REASON_MODEL` | `stocklink-reason` |
| 低成本决策 | `V4flash_CHAT_MODEL` | `deepseek-gangtise` |
| 快速推理 | `V4flash_REASON_MODEL` | `deepseek-gangtise-thinkinkg` |
| 低成本决策备选 | `QWEN32B_FLASH_MODEL` | `gangtise-flash` |
| 无思考低成本决策 | `QWEN32B_FLASH_NOTHINK_MODEL` | `gangtise-flash-nothink` |
| 视觉理解 | `VL_MODEL` | `gangtise-vl` |

当前 NPC 时段选择推荐使用 `deepseek-gangtise` 或 `gangtise-flash-nothink`；高价的 Pro/Reason 模型留给后续重要对话、日终反思和剧情节点，不应用于 200 人每时段常规决策。

## 本地配置与待补前置条件

Godot 中按 Esc 打开接口面板，选择“兼容接口”，填写 Base URL、模型名和 API Key 后应用。配置文件位于 `user://llm_interfaces.cfg`，已被 Git 忽略，但它本身不是系统钥匙串且没有加密；共享电脑不应勾留正式密钥。

真实联网测试仍需要确认服务的 API Base URL，并确认服务兼容 `POST {Base URL}/chat/completions`、Bearer Token 和标准 `choices[0].message.content` 响应。该前置条件补齐前，所有自动回归只使用假提供方或离线规则，不消耗正式额度。

## 验收结果

自动测试覆盖动态槽位、6 人觉醒上限、主观记忆来源、私有数据不进入公开视图、非法候选拒绝、服务失败回退、每时段调用上限、Token 账本、模型名称以及密钥不进入检查点。Godot 验收要求：项目可启动、地图与 NPC 正常活动、人物面板可觉醒 NPC、离线时连续推进不报错，接口未配置时不会访问外网。

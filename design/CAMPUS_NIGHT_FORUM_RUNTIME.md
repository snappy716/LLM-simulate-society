# 校园夜相论坛与 NPC 自主行动运行时

## 目标

本阶段让夜相不再只是玩家可切换的显示层，而是一个没有玩家参与也会推进的受限社会系统：每晚发布固定数量的异常委托，少量合格 NPC 自主进入、浏览、竞争、移动并完成任务，未解决事件在晨光到来时留下明确的过期记录。

## 权威流程

1. 每天晚间发布 20 个夜相委托。委托来自数据模板，可以在不同校园区域重复出现，但每次都有独立任务 ID、锁版本、发起者与历史。
2. 从 `capable` 和 `willing` NPC 中选出 6～12 人。选择考虑夜相意愿、风险承受、利他性、好奇需求、当前污染、表世界硬职责和已有任务，不做纯随机抽人。
3. 入场是免费行动，只改变同一角色的 `layer` 与污染值，不复制角色、背包、关系或地点。
4. NPC 晚间浏览 2～4 个可达委托，按学院适配、技能、路线和个人属性锁定一项。锁定后其他玩家或 NPC 无法重复接取。
5. NPC 深夜才执行已锁定任务，因此玩家能在晚间看到委托逐步被接走，也给 NPC 在行动前发起协助或组队请求留下窗口。
6. 任务执行复用校园统一寻路、主要行动预算、活动效果、奖励、关系后果和人物年表。每名 NPC 每夜最多执行一项主要夜相委托。
7. 天亮强制退出夜相；未完成委托过期并清理执行者指针，不能留下跨层活动任务。

## 玩家可见边界

- 未首次进入夜相前，公共快照不会包含夜间任务，手机中的里世界频道显示“未发现”。
- 首次进入后永久开放历史浏览；身处表世界时只能查看，身处夜相时才能接取和执行。
- 玩家与 NPC 使用同一原子任务锁和行动效果，不享有优先选择权。
- 公共视图只显示活跃人数、任务竞争数量和已经发生的记录，不公开完整参与者名单、内部评分或未来选择。

## UI 原型

当前手机论坛使用经典 RPG 的分层信息结构：顶部切换“表世界 / 里世界”，第二层切换“可接 / 我的 / 已结束”，任务卡片展示状态、地点、截止与竞争，详情页展示层域、来源、目标、奖励和动态记录。颜色和最终写实学院风素材留给后续 UI 精修，本阶段只保证信息结构、状态反馈和交互契约稳定。

## 后续依赖

下一阶段的人物牌部署和卡牌战斗会消费夜相任务的队伍、地点和敌情上下文。当前夜相委托以文字活动结算；战斗型任务在战斗运行时完成后再改为进入战斗并依据胜负结算，不需要重写论坛竞争流程。

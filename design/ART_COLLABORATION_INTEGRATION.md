## 2. 已接入内容

### 2.1 五张校园区域最新版

`game/assets/maps/campus_collab/` 只保留五个区域的最新版。数据目录
`game/data/campus_art_catalog.json` 为每张图记录稳定 ID、分组、语义区域、图片尺寸、出生点和
当前粗略可行走矩形：

- `campus_gate.png`：校门与教学楼；
- `living_area.png`：校园生活区 V2；
- `east_dormitory.png`：东区宿舍 V5；
- `west_dormitory.png`：西区宿舍 V3；
- `psychology_bridge.png`：心理学院与校园桥 V6。

其余 15 张历史迭代稿/废案不进入运行资源，但保留在原始 RAR 和 Git 历史中。五张最新版都能在
同一 Godot 场景中切换，不会因为不同分辨率沿用错误的镜头边界。

### 2.2 地图浏览与权威传送

在 `res://scenes/campus/campus_collab_test.tscn` 按 `M` 打开五区地图目录。选择其他校园区域时，
向 Python 内核提交 `FAST_TRAVEL_CAMPUS`，按真实地点图检查可达路线后更新玩家
  地点，再切换对应画面。

地图移动遵循已确定规则，不推进分钟、不消耗主要行动。内核会为途经的每一段路线生成
`ACTOR_LOCATION_CHANGED` 事件，存档和后续系统可以追溯，而不是由 Godot 直接篡改坐标。

五张最新版地图还组成了可实际步行的双向网络。生活区是当前素材覆盖范围内的视觉枢纽，分别连接
校门、东区宿舍、西区宿舍和心理学院/校园桥；玩家走到带箭头名称的画面边缘时，Godot 先提交对应
道路给 Python 内核，验证成功后才切换图片并将玩家放在目标地图的对应入口内侧。失败时保留原地图
和位置。`M` 地图仍是可选的快速移动方式，不是五区互通的唯一方式。

### 2.3 玩家、模块化人物与 NPC

- 玩家继续使用 `player.tscn` 和 `ModularCharacter`，支持 WASD 移动、待机/奔跑动画与七层外观；
- 按 `R` 可在联调阶段验证模块化外观组合；
- NPC 继续从 200 名权威角色中选择当前画面可见者，按每个时段的实际决策路线移动；
- NPC 到达目的地后不会立即从画面消失：当前区域最多保留 18 名真实在场角色，并在地图切换、
  快速移动和时段推进后按权威地点重新投影；
- 普通 NPC 不显示头顶名称或状态文字，玩家靠近后才出现 `E 查看` 提示；
- 公开查看面板只展示姓名、身份、实际地点、可观察活动与模糊情绪，不直接展示需求数值、秘密、
  内部模拟层级或未来计划；
- 未导入协作包内只会随机游走的旧 NPC 控制器。

### 2.4 镜头与移动

- 地图切换时自动读取图片宽高并更新 Camera2D 边界；
- 玩家位置限制在每张图当前的粗略行走矩形中；
- 五区出口、目标地图和进入位置由 `campus_art_catalog.json` 数据驱动，不写死在角色脚本中；
- 左下角提供 1×、2×、3×整数缩放；
- 鼠标靠近画面上/下边缘时可纵向浏览，离开边缘后平滑回到玩家观察位置；
- 现有道路跨区和楼梯进入室内仍使用权威通行系统。

### 2.5 手机 UI 原型

按 `T` 打开手机，当前提供校园通讯、课程平台、校园相册、备忘录、校园商城、电子钱包、健康档案
和双层论坛入口。课程、场景、当前位置、活动、资金、需求与情绪读取现有快照；表世界论坛现已
接入任务列表、详情、竞争人数、接取、放弃与完成，里世界频道和消息认知仍保持未解锁。手机、地图与 NPC 查看面板互斥，打开时暂停
玩家移动。

## 3. 未接入的冲突内容

- 协作包 `SceneTravel` 的硬编码地点和坐标：会绕过 Python 地点图、开放时段与事件日志；
- 协作包的随机 NPC 控制器：会让画面行为与 NPC 日程和决策不一致；
- 重复的角色脚本和角色图片：当前项目实现覆盖范围更完整，重复导入会形成两套权威来源；
- 现实应用品牌和纯占位手机文案：已改成校内通用入口，并只显示当前确实存在的数据；
- `.godot/`、`.import`、`.uid` 等缓存：由当前 Godot 版本自行生成，不属于源代码。

## 4. 当前限制与下一轮美术要求

五张图都是扁平 PNG，不包含前景遮挡层、碰撞层、入口遮罩或源工程。因此本轮能够浏览、移动、
缩放、边缘步行换区与传送，但每张图仍只有粗略行走矩形，不能保证角色绕开所有树木、建筑和栏杆。

每个最终采用的区域下一轮应交付同尺寸、同坐标的背景层、地面层、前景遮挡层、碰撞遮罩、入口和
道路锚点表、原始可编辑文件、字体清单、素材来源与商业许可，并提供去除真实校名和品牌的发布版。
废案可继续在原始交付包中作为开发对照；正式关卡只基于这五张最新版制作精确碰撞。

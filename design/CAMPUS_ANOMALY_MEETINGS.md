# 第 10 步第三批：主动求助、约见与实际白天支持

2026-09-09。基线 `d28956e`。本批补齐人物不能只靠偶遇获得支持的问题，不新增临床诊断、主线或日内大模型调用。

## 玩家的完整操作

1. 先在人物面板听取对方自愿提供的月相经历。有联系方式、本人愿意、自己的对应理解至少 20 后，可选择未来三天内的白天与开放公共地点，提出支持预约。
2. NPC 可以自行从已有信任联系人中求助。发给玩家的预约保持待回复，不自动接受。在手机“校园通讯”选择该联系人即可同意、婉拒或取消，不需要先去找到他；对话消息保留约定。
3. 确认后，约定时段的 NPC 会通过原有道路和门口赴约，并保留一次主要行动。玩家仍需自己走过去，不自动移动或收费。
4. 到场后重新询问此刻体验，再执行“共同做现实锚定”。沿用同一知识、可靠证据、当下同意和双方行动检验；实际完成才回写原事件。
5. 可以改变主意。取消只释放预留，不返还已经用过的行动；时段结束仍未完成则记为未赴约/未完成，不推断失踪，不扣行动、不产生疗效。

预约、真实到场、支持完成是三个不同事实。人物日志中的“赴约并等候”不等于已帮助对方恢复；生命、专注、物品和金钱不因预约变化。

## NPC 自主链

每天早晨，在既有完整日计划窗口执行一次有边界的规则求助：依据自己真实残留经历、现有联系方式、信任和可用时段选一位联系人。不是把所有人的私人知识值交给求助者筛选。帮助者收到后检查自己的理解、关系和意愿，可以拒绝；玩家必须亲自确认。

同一事件最多一个待回复/已确认预约。自主求助每个事件每天尝试一位有兼容时段的联系人；同一联系人两天内不重复催促。玩家同一天同事件同帮助者不能反复重约。此冷却针对游戏内预约，不是聊天或 LLM 请求次数限制。

NPC 与 NPC 确认后分别经统一日程执行器寻路；所有人物移动阶段完成后，检查双方真的在约定地点，再使用 `ASK_ANOMALY_EXPERIENCE → SUPPORT_ANOMALY`。没有玩家的情况下也可完成；没有知识、意愿、证据或行动则不伪造成功。

## 保护原有安排

- 只约上午/下午、未来三天的镜湖广场或图书馆阅览大厅。开放时间和双方道路访问权限均校验，实际执行再次检查。
- 不覆盖优先级 90 及以上的课程/工作、已接论坛委托、同一时段出击或已确认社交会面。紧急安全/生活需求、受困、战斗或失去行动能力会使预约取消或无法完成。
- 已确认支持时段不能被自动采购抢走；其余时段生活计划照旧，完整 LLM 判断仍只在过夜进行。
- 与现有出击预约一致，采用保守的独占委托保护：有尚未结束支持预约的 NPC 暂不新增论坛任务。它不会撤销已有委托；后续具备可靠耗时预估再允许不冲突的短任务。
- 当期双方各预留一次主要行动。普通聊天、电话、走路和购物仍不收费；要改做其他主要行动，先取消预约。
- 双方未来日程不是神谕：后来出现不可用、已接受其他义务或撤回意愿时会记录取消，不强行兑现。

## 数据与边界

新增可选 `situations.anomaly_meetings` 账本，含每天求助标记和预约记录；老存档缺失时合法。状态为 pending、confirmed、declined、cancelled、missed、completed。记录参与者、真实事件、发起者、创建/约定时段、地点、消息编号、版本和实际支持凭据。

`PROPOSE_ANOMALY_MEETING`、`ACCEPT_ANOMALY_MEETING`、`CANCEL_ANOMALY_MEETING` 是正式事务；非参与者无法读取/操作，过期版本不能覆盖新决定。内部等待只表示到达，不向玩家公开一个可直接写成功的行动。完成必须对应同一事件、帮助者、日期、地点的真实白天支持记录；不能凭预约伪造已完成。

API 的 `social.anomaly_meetings` 只给当前玩家参与的预约；不会暴露他人预约或月相数值。人物面板选项和手机操作复用既有桥接，NPC 次日模型上下文只获得自己的预约。手机历史沿用既有每线程保留窗口，不承诺无限保存全部消息；长期结果留在事件/预约账本。

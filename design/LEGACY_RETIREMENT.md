# 旧城镇下线清单

2026-09-05 用户明确允许删除旧城镇，覆盖此前必须保留旧工程的约束。只删除旧城镇，不删除七张校园图、校园复用的人物/动画、通用 LLM 接口或用户私人世界观文件。

## 第一批：独立副本退出仓库

- 删除仓库中的 `emergent_town_demo/`、`project-a-0.2/`、`ProjectA-0.21.zip`，共 148 个已跟踪文件。删除前旧版 46 项测试通过；本机将原目录连同未跟踪/被忽略的运行数据一起移动到仓库外备份，避免把私人配置当作废弃代码清空。
- Git 历史保留这些文件，恢复参考删除前提交 `3f570ca`。不清洗 Git 历史，不强推，不合并 main。
- 移除三个依赖旧源文件的逐项等价对照测试；原文件中的三个仍有效的快照/Schema/迁移测试迁到 `test_architecture_contracts.py`，并新增旧副本不存在、校园入口存在的检查。不把测试数量下降当成功能减少，也不跳过校园测试。

## 第二批：校园独立启动（已通过验收）

- 正常服务不再创建旧 `World`；新进程导入并启动校园后，`simulation.runtime` 和 `simulation.api.legacy_bridge` 均不在已加载模块中。200 名校园 NPC 不变，没有偷偷运行第二套 200 人社会。
- 配置加载抽到 `simulation/settings.py`；包入口改为校园服务。旧桥接只留在 `simulation/api/legacy_bridge.py`，仅历史功能测试显式导入，不挂生产 HTTP。这是隔离，不是全量删除旧运行时。
- Godot 默认主场景改为七图校园，启动握手直接读取 `/kernel/campus-snapshot`。旧 `/snapshot`、`/step`、`/trade`、`/use-item`、`/action` 明确返回 410，不自动重建旧世界。
- 通用 API 设置成为共用常驻面板，可从校园手机打开；没有其他面板时 Esc 可打开/关闭。暂停、关闭恢复、遮挡时禁开其他面板有测试。配置不会自动联网，启动仍离线，不增加聊天次数限制。
- 保留工程的原用户数据标识，已有接口配置和手动槽位置不变；内容版本未变。实读改动前的校园存档，除运行版本单调递增外，完整状态和 RNG 与磁盘原档一致。
- 全局 481 项、专项 7 项、Godot 默认启动/设置与原有各流程、七日自然模拟通过，详见 `production/VERIFICATION.md`。Mac 实测，不代表 Windows 发布验收。

## 剩余下线顺序

1. 服务启动解耦已完成，保留独立新进程验收，防止后续又引入旧世界初始化。
2. 校园默认入口、API 设置与存档目录兼容已完成；旧调试场景仍在文件树中，但旧 HTTP 已下线，不应作为正常游戏入口。
3. 下一批清理旧人口显示层、旧 UI、自动加载桥中的旧接口分支、旧地图工具、廷根地图和对应场景；七图、模块化人物、相机与共用设置面板保留。
4. 校园内容注册器仍加载旧物品目录、商店、通路和地点；部分物品数据被校园映射复用。先抽出校园实际使用的数据，再删除纯城镇定义。内容哈希会变化，须提供仅针对这次确定性裁剪的校园存档迁移，不能让刚实现的校园存档失效，也不能把旧城镇人物转换成校园人物。
5. 清理不再可达的旧 `runtime`、系统、故事及测试；保留真正被校园调用的共用算法。相应旧测试是随退休功能删除，校园交易、资源、任务、LLM、卡牌、路径与存档测试必须保留并回归。
6. 每批做全局、Godot 实际运行及对应多日检查后上传开发分支。全部解除后，才能声称“旧城镇已完全下线”，再继续原路线第 3 步 UI 统一。

目前完成独立副本移除和校园启动解耦；生产启动已不运行旧世界，但旧素材、兼容测试及部分共用内容仍待裁剪。这份清单是优先前置，不新增玩法需求。

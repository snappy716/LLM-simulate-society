# 校园关系与行动小队运行系统

> 状态：第 11 步第一版运行时已实现
> 范围：邀请、接受/拒绝、同行承诺、三人队伍、稳定度、关系协作能力、参战意愿与手机灰盒 UI

## 1. 定位

行动小队不是独立于校园社会的“战斗角色栏”。人物能否加入、愿意留多久、队伍是否稳定，都读取同一名
NPC 的关系、人格、需求、学院、社团和夜间行动能力。队友仍是世界中的持久 NPC；加入队伍不会复制人物，
也不会绕过其日程、任务、物品、伤势或后续 LLM 认知。

第一版队伍固定最多三人，包含队长。这一上限来自已确定的前、中、后三排人物牌战斗结构，而不是社团人数
限制。玩家开局拥有一个单人行动小队；系统接口也支持由 NPC 担任队长，等夜相任务提供真实组队目标后即可
由规则 NPC 使用同一套邀请和承诺规则。

## 2. 邀请与自主决定

`INVITE_PARTY_MEMBER` 是免费社交行动，不推进时钟、不消耗主要行动。它只表达邀请，不保证成功。目标 NPC
根据以下信息计算当前意愿：

- 是否已经具备进入夜相并行动的能力；
- NPC 对队长的信任、亲近、尊重、人情、怀疑、恐惧和冲突；
- 风险承受、利他倾向；
- 安全、休息与承诺压力；
- 是否同学院、是否有共同社团；
- 是否已经承诺加入其他队伍。

Godot 只显示“较愿意、态度不明、较可能拒绝、当前不可邀请”等模糊判断，不公开 `night_access` 或内部
评分。拒绝仍是一次已经发生的社会事件，会进入双方人物年表；同一天不能对同一人物反复邀请。

## 3. 同行承诺

接受邀请后，NPC 以 `committed` 状态加入队伍，并承诺至少履行到策略规定的日期。接受会小幅增加双方熟悉
和信任，并增加受邀者对队长的人情。队长可以解除成员承诺，成员在最低承诺期结束后也可以离队。

每天上午，NPC 会重新检查已经到期的承诺。若夜间行动能力消失，或关系与心理压力已经使意愿低于退出
阈值，NPC 会自主退出并产生正式事件。接受阈值高于退出阈值，因此人物不会仅因一次轻微波动就在加入后
立刻反复退队。

## 4. 队伍稳定度

稳定度是实时派生值，不保存第二份容易过期的副本。系统读取成员之间双向关系、全队承诺压力和已激活的
关系协作能力，得到 `0～100` 分及四档描述：脆弱、磨合中、稳定、默契。

关系变化会立即反映在下一次快照中。后续战斗只读取该派生结果，用于撤退分歧、保护倾向、协作牌效果等，
不能在 Godot UI 内自行修改稳定度。

## 5. 关系协作能力

随机 NPC 已有的五类关系能力现在拥有正式运行定义：

| 能力 | 当前效果 | 后续战斗接口 |
| --- | --- | --- |
| 稳定搭档 | 提高队伍稳定度 | 阵型稳定 |
| 共同专注 | 提高队伍稳定度 | 初始专注 |
| 相互掩护 | 提高队伍稳定度 | 首次保护 |
| 鼓舞陪伴 | 提高队伍稳定度 | 回合结束专注恢复 |
| 协同行动 | 提高队伍稳定度 | 首次换位费用降低 |

能力只有在来源人物对其他队员的信任未跌破条件、冲突未超过条件时激活。当前阶段只结算稳定度并输出经过
验证的 `battle_effect` 预览；实际卡牌和战斗效果留给第 15～16 步。

## 6. 权威状态与事件

`WorldState.parties` 是唯一队伍账本。成员名单、承诺、队长、用途、修订号和邀请历史都由事务处理器修改。
关键事件包括：

- `PARTY_INVITATION_DECLINED`；
- `PARTY_MEMBER_COMMITTED`；
- `PARTY_MEMBER_DISMISSED`；
- `PARTY_MEMBER_LEFT`；
- `PARTY_MEMBER_WITHDREW`；
- `PARTY_DISBANDED`。

所有事件自动投影到人物年表。一次邀请如果在满员、重复邀请或目标已加入其他队伍等前置检查处失败，不会
产生半完成的关系或成员状态。

## 7. 当前边界与下一步

当前没有凭空让 NPC 随机组队。原因是夜相、里世界任务和异常目标尚未接入，缺少“为什么组队”的世界内
动机。系统已支持 NPC 队长和通用队伍账本；第 14 步接入夜相任务后，NPC 可依据任务目标调用同一套规则
邀请、承诺、行动和后台战斗。

下一步进入第 12 步 NPC 认知与 LLM 决策。LLM 只能从规则层已经判断为合法的邀请、任务和行动候选中选择，
不能直接把 NPC 塞入队伍或改写稳定度。

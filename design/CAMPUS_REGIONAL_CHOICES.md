# 第 9 步第七批：区域风险与 NPC 的实际选择

2026-09-08。承接持续局势、论坛竞争和次日认知，不新增日内完整 LLM 判断，也不限制玩家聊天次数。本批仍不是第 9～12 步整体完成。

## 玩家实际能看到什么

NPC 在里世界论坛浏览公告后，会把公告中的地区风险与自己的性格、状态、生活地区一起纳入接单评分。相同任务，对责任心强、愿意冒险且准备充分的人，可能是值得帮助的机会；对受伤、受污染、重视安全的人，则是需要谨慎权衡的选择。

正式承接有风险公告的任务时，NPC 留下一句简短理由，显示在论坛详情的“承接者留言”和动态记录中。这不是隐藏属性面板，不公开健康数值、性格评分或私人认知账本。留言是规则计算的理由，不冒充实时生成的 LLM 台词。任务仍由原有错峰浏览、考虑、原子锁、寻路和执行机制处理；玩家不享有优先权，也不会被系统替代做选择。

放弃或战斗撤退释放任务后，清除当前承接者留言；历史仍保留当时事实。新承接者重新形成理由，不继承上一个人的态度。留言本身不保证完成任务或获得额外奖励。

## 评分边界

仅对已发现里世界论坛、实际查看过的夜间任务生效。采用帖子发布时的 `pressure_at_creation`，不偷读当前隐藏的地区压力。旧帖子不会因为现场后来变化而自动改写内容或历史。

在既有路线、学院、社团、技能、洞察和专注评分之外，加上一个有限修正：

```text
责任 = 利他 / 100 + 尽责 / 200 + 本地生活关联（有则 0.5）
谨慎 = (100 - 风险承受) / 100 + 安全需求 / 100
       + 自身污染 / 80 + (1 - 当前生命 / 最大生命)
修正 = clamp(公告压力 × 2 × (责任 - 谨慎), -36, 36)
```

本地关联来自人物现有住所或主要活动地点。修正不覆盖职业技能和通行条件，也不等于绝对拒绝风险；NPC 仍是在自己看到的可选任务之间综合比较。没有看到高风险帖子的角色不会凭空获得风险知识。

## 次日认知与存档

每人每地区保留最新一条已读公告摘要：地区、发布日、实际阅读日、发布时压力和来源任务。较晚读到旧帖不会覆盖新帖。直接接单也代表已阅读该帖，但评分选择阶段不会提前把未看的帖子当作已知。

夜间到次日的 `BoundedDecisionRequest` 只加入该 NPC 自己最近的至多六条已读摘要；不是全地图实时状态。此处不新增模型请求，原有合法日程与行动校验仍是执行门槛。面对玩家的普通对话上下文不自动塞入这份夜间私有账本。

可选 `cognition.regional_awareness` 与任务 `situation_choice` 跟随检查点保存；旧档没有这些字段仍可运行。新不变量检查来源任务、阅读者、地区、日期、压力范围和当前承接者，拒绝损坏的观察或留言凭据。后台完整 LLM 规划仍只在跨日进行，日内论坛注意力是规则执行。

## 压力累计调整

此前同一区域的多个未处理现场分别 +2，在每晚固定 20 个委托、实际行动人数较少时，会把任务密度重复计成地区恶化。

现在同一区域同一晚的过期现场合计最多 +2，每个现场仍有独立后果来源与处理凭据；其他地区、其他晚上的过期各自计入。实际处理一个现场仍 -3，每跨日自然回落 1，范围仍为 0～12。重复评审、读取旧凭据不会对同一区域同一晚重复加压，也不会返还已经消费的资源。

已发布任务、战斗和历史不追改。每晚仍生成 20 个夜间委托，压力仍影响下一批地区模板权重与实际后续暴露。这只是初版平衡调整，不能据七日样本宣称 28 天或所有种子已平衡。

## 同批修正的接单边界

寻访对象不浏览承接自己的寻访委托；旧的待接记录即使指向自己的寻访，也安全释放，不使整个校园动态失败。失去行动能力的人不继续浏览接单。这不把无回应直接判为失踪，也不自动治疗或完成寻访。

## 验收与下一步

证据和最终计数见 `../production/STEP_09_REGIONAL_ACCEPTANCE.md`。专项涵盖已读/未读边界、相同公告下不同选择、实际查看/接取/放弃/重新接取、私有上下文、检查点、真实过期现场合并加压、历史凭据去重和寻访独立性。Godot 实际打开双论坛并检查自然 NPC 的接单留言，保留未解锁过滤。

本批不把规则样本的多样性归功于大模型。下一步继续补齐第 9 步的证据驱动调查选择与可追溯后果，再依次开展失心者多解法、七天介入对照和生活内容。长期频率、LLM 对照和 Windows 原生发布验收仍保留明确边界。

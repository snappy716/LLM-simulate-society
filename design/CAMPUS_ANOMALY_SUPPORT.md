# 第 10 步第一批：具体人物的月相残留与白天支持

2026-09-09。遵循 `CAMPUS_WORLD_AND_GAMEPLAY_DESIGN.md`：受影响者首先是人，不以真实精神疾病、孤僻、压力或未回应作为怪物判据。主角的行为是知情陪伴和虚构月相的现实锚定，不是学生进行临床治疗。

## 玩家入口与实际成本

人物面板新增“听取本人月相体验”。当面或已有手机联系方式、双方处于可活动的表世界时，可免费询问；本人可以拒绝。没有实际月相遭遇，不造出经历。重复听取同一时段、同一版本的陈述不增发证据、不改变关系或生命值。普通 LLM 聊天仍不限制次数。

本人同意透露后，面板只展示有日期的陈述和操作条件，不显示内部的外壳/心结/自洽度、隐藏位置或案件状态。旧陈述不会因后台进展自动变成当前事实。只有已经收到这份陈述的人才有此条记录。

“共同做现实锚定”是一次正式主要活动，不是普通聊天收费。需要：

- 上午或下午、同一开放地点，双方可以行动，没有战斗或受困。
- 对方此刻愿意参与：其对帮助者信任至少 50、怀疑低于 60、冲突低于 50；普通倾听信任门槛为 35。
- 帮助者对应实际来源现象的理解至少 20，来自已有阅读/上课/案例系统；一次理论阅读即可达到门槛，但会正常消耗阅读行动。
- 同时段、同版本的本人陈述，帮助者真实持有且可信度至少 0.5、失真不超过 0.35。别人的线索或泄露的案例 ID 不能代替本人同意。
- 双方各有一次主要行动，没有已接受的论坛委托或出击预留。成功原子扣除双方成本，不自动推进时段；拒绝时不扣任何一方。
- 同一次经历每天至多一次正式锚定，不因更换帮助者、重复点击或读档而绕过。普通交流仍可继续。

实际效果只进入月相残留账本，不恢复生命、专注，不造物资、不发金钱、不自动完成原夜间任务，不把回访等同于医疗。

## 权威数据与第一版参数

`situations.campus_anomalies` 为可选、按需建立的版本 1 账本。源于已有夜间现场中实际被困的持久人物，在现场已正式处置或随天亮失效、人物脱离后建立。不是每次压力增加都随机抽一个“病人”。每人同时至多一个未稳定的事件；旧档不会补造前一日以前的历史事件。

| 字段 | 初值 | 一次有效白天锚定 |
| --- | --- | --- |
| shell：污染外壳残留 | 30 | -10，最低 0 |
| core：与现实联系尚未恢复的心结 | 60 | -20，最低 0 |
| coherence：异常解释的自洽度 | 60 | -20，最低 0 |

这些是可调的虚构玩法数值，不是临床量表。第一版连续三个不同日期的有效活动可将这次残留稳定：`unsettled → easing → resolved`。这条路线的代价是知识准备、信任、实际见面和多天双方行动机会；不会强制玩家进入夜相。恢复生命/专注仍遵守原休息全恢复规则，并不抹去已经发生的经历。

每次写入保存来源现场/任务、真实人物、对应现象、版本、原始状态、当前状态、本人报告、帮助者、日期、所用证据及前后值。断言验证来源与效果链；不存在任意写入成功或模型改数值的接口。新增请求契约为 `contracts/anomaly_request.schema.json`。

## NPC 不等待玩家

正常时段执行阶段会检查受影响者已有、在场、可信任且有对应知识的联系人；通过同一询问和支持处理器执行。没有合适帮助者就保留未解决状态，不瞬移、不增造联系人、不自动消耗玩家的行动。双方原有任务和行动预算优先得到保护。

已知本人陈述以日期和摘要提供给**该接收者自己的**次日规划上下文；不提供全校异常清单或隐藏数值。没有新增日内模型请求；普通人物也可以执行规则支持。第三批另补有边界的主动求助与约见，见 `CAMPUS_ANOMALY_MEETINGS.md`：既有联系人确认后保护时段，经真实道路赴约，再使用同一支持处理器；预约不是疗效，不自动操作玩家，不声称已具备任意模型自主治疗规划。

2. 加入证据洞察与身份/关系锚点，区分单纯压制、白天解决、昼夜联合、拒绝/失败/未介入的代价；复用本账本，不开第二份相互矛盾的“已治好”标记。
3. 七天同一事件介入对照，检验长期稳定、复发边界与玩家可见线索。自然样本出现支持的频率和故事质量必须另验，不能靠受控夹具证明。

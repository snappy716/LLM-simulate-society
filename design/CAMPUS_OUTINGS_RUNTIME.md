# 自愿相处与约会：运行时边界

2026-09-10，第 12 步第四批。89 个模块/844 项 Python、57 条后台 Godot 完整通过，见 `../production/STEP_12_OUTINGS_ACCEPTANCE.md`；本文件不证明远端上传状态，也不表示第 12 步整体完成。

## 玩法与正式行动

手机「日程与约定」新增「相处与约会」。只显示已有联系人；选择未来三天内下午或晚间的镜湖广场/图书馆公共地点，可以明确邀请普通共同活动或约会。接受只是确认这次活动，不自动确立恋爱、排他或永久承诺；拒绝和取消不扣关系分。

正式命令：`INVITE_CAMPUS_OUTING`、`ACCEPT_CAMPUS_OUTING`、`DECLINE_CAMPUS_OUTING`、`CANCEL_CAMPUS_OUTING`、`ATTEND_CAMPUS_OUTING`。

- 邀请及回应免费，双方各预留一个主要行动，互查公开活动、出击、支持和短暂见面；不得覆盖原有重要课程/工作或未完成委托。
- 玩家永远自行接受、自行到场确认。NPC 依据自身关系、性格、社交需求及安全/生活压力回应；亲密关系的门槛不是魅力检定，也不是购买恋爱关系。
- NPC 按统一道路实际赴约。到场确认本身不付主要行动；双方均确认、仍同地可活动且各有预算时，原子结算两人的行动。
- 仅完成时增加双方少量熟悉、亲近和信任，记录实际地点、时段、行动收据和共同经历。未见面、晚到、离开、当前拒绝、已失去预算均不伪造完成。
- 时段结束未完成，记录真实到场者并关闭约定；不推断失约原因、不治疗、不恢复生命、不返还其他活动已花掉的行动。
- 同一对人物同一时段不反复催促；这属于互动行为规则，不是聊天或 LLM 请求额度。

## NPC 自主性与 LLM

原有每日完整规划加入可选的熟人共同活动，受社交需求、外向倾向、本人关系和实际开放道路影响。规则人物与 LLM 人物都从同一候选中选择；候选并不保证被接受或实际完成。

跨日生成计划后，尝试其中一次主动邀请并记录回应；其他已确认约定先参与冲突核验。受邀者可以拒绝，玩家邀请保持待回应，未获确认时执行原日程。已确认的共同活动不能被自动里世界入场覆盖。日内不增加重新规划请求。

自主候选目前采用普通相处意图，不凭空替人物宣布恋爱意向；明确约会邀请走同一协议和实际参与结算。不是完整恋爱偏好、排他关系、伴侣剧情或告白系统。

## 状态、隐私与依赖

- 权威账本为可选的 `state.situations.campus_outings`，旧存档没有它仍能恢复，不改物品内容版本，也不补造历史经历。
- 复用原有联系人、手机消息、稀疏关系、行动预算和道路；不新建金钱或关系数据库。
- 日程只展示本人的邀请与经历；共同收据不会泄露对方剩余行动或对自己的私有关系数值。其他 NPC 的私密日程不可浏览。
- 已完成经历可作为原有「共同经历锚点」的候选来源；仍须当前本人陈述、明确同意及对应知识，绝不自动生成心理诊断或恢复效果。
- 运行时先核验双方行动预算，再一起结算；只复制预算做预检，避免每对相处都复制整个长期世界历史。

## 本批验收要求

正式邀请/回应/撤销、双向日程冲突、真实移动、NPC 双方与玩家赴约差异、双预算原子性、失约无收益、去重、隐私、存读档、伪造收据拒绝、共享经历来源、既有每日模型协议选择。Godot 用真实 HTTP、手机按钮和场景，不把直接改存档视作完成。

开发测试全部采用离线或内存伪提供方。伪提供方验证候选和执行协议，不证明真实 LLM 的自然社交质量；不运行付费多日 API 测试。

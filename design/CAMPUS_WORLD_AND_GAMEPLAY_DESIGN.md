# 《失物之城》校园社会模拟 RPG Demo 设计大纲

> 文档性质：当前讨论结果的统一设计基线
>
> 项目范围：双人团队、半年完成可公开试玩的完整 Demo
>
> 当前策略：先完成沙盒、NPC 社会与核心玩法，再接入完整主线表现和美术资源
>
> 版本说明：本稿取代旧版 14 天、晨报暗语和固定学院队友方案；本分支只建立架构地基，不切换现有运行时
>
> 剧透警告：本文包含导师、失踪学生和 Demo 结局真相

## 1. 一句话定位

《失物之城》（暂名）是一款发生在现代大型大学校园中的自主社会模拟 RPG：白天，玩家上课、阅读、参加社团、兼职、交友、恋爱和调查异常；夜晚，受污染月光影响的同一座校园显现“夜相”，玩家可以进入其中，以无格子、无站位的技能指令回合制战斗处理怪物和失心者，也可以留在表世界继续生活。

真正的核心不是战斗，而是：

> 一个即使没有玩家参与，NPC 也会持续生活、交易、建立关系、发布和接受任务、调查异常、组织队伍、进入夜相，并留下可被玩家观察和介入的故事的校园社会。

## 2. Demo 核心支柱

### 2.1 自主发展的校园社会

- 约 200 名持久化 NPC 拥有身份、位置、日程、物品、金钱、关系、需求、技能和行动次数。
- NPC 可以自主发布、查看、接受、转交、完成、失败或放弃任务。
- NPC 能自主交易、参加课程和社团、结交或疏远他人、准备夜间行动。
- 玩家没有参与的事件仍会推进，并通过论坛、关系、库存、伤势、场景痕迹和后续任务反馈。
- 主线真相由规则固定，事件过程和参与者允许动态变化。

### 2.2 玩家选择自己关心的人

- 除主线不可替代角色外，Demo 前期不制作大量固定队友。
- 普通校园角色使用约束式随机生成，并在第一次进入持久模拟时固定身份。
- 任何满足条件的持久化 NPC 都可能成为朋友、恋爱对象、竞争者、任务伙伴或夜间队友。
- 玩家通过有限的“记名/觉醒”权限，将少数自己重视的 NPC 提升为长期 LLM 深度认知角色。
- 觉醒赋予更强的记忆、反思和自主规划，不赋予玩家控制该 NPC 的权力。

### 2.3 昼夜双层生活

- 表世界负责校园生活、知识成长、关系、交易、调查、准备和现实干预。
- 夜相负责异常探索、纯怪物战斗、失心者救援和秘密组织活动。
- 夜晚可以不进入夜相，改为读书、社团、约会、兼职、整理情报、支援他人或休息。
- 白天的调查、关系、证据、装备和知识会改变夜间难度与解决方式。
- 夜间结果会改变第二天的课程、医疗、安保、商店、社团和论坛内容。

### 2.4 知识就是成长

- 阅读获得理论，调查和战斗获得案例，应用和反思形成真正理解。
- 知识首先解锁新行动、敌人规律、对话和非暴力解法，其次才提供有限增伤。
- 身体锻炼、课程、社团和工作提升基础属性与专业能力，并在生活玩法中持续生效。
- 不采用依赖刷怪的传统等级体系。

### 2.5 有 DDL、但不等待玩家

- Demo 共 28 个游戏日，分为四个 7 日阶段。
- 每阶段都有明确 DDL，来源于月相、制度流程、人物计划或异常演化。
- 任务由玩家与 NPC 公平竞争；没有玩家优先，也没有 NPC 优先。
- 玩家无法在一次流程中完成所有任务，错过会产生新的世界状态，而非全部变成 Game Over。

## 3. 世界与空间背景

### 3.1 虚构校园

暂定地点为“栖潮市·新岬大学镜湖校区”。校园只参考大型郊区研究型大学的功能规模，不复制现实学校的名称、地图、建筑或人物。

- 校园位于大都市外围的山湖交界处。
- 教学、科研、住宿、医疗、购物、安保和娱乐设施完整，足以形成小型社会。
- 校内包含新旧两个建设时期不同的片区。
- 与市区有公共交通，但夜间班次有限。
- 玩家不是被强制困住，而是因为课程、住所、经济、关系和事件自然集中在校园。

### 3.2 功能区域

| 区域 | 表世界作用 | 夜相作用 |
| --- | --- | --- |
| 正门与安保中心 | 出入、访客、失物、监控 | 身份检查、封锁、替名异常 |
| 教学区 | 上课、考试、教师办公室 | 错位教室、无限点名、课程表异常 |
| 图书信息中心 | 阅读、借阅、档案、网络 | 删除姓名、失控目录、知识失相 |
| 心理学中心 | 课程、研究、咨询转介 | 梦境实验、失心者、主线线索 |
| 实验区 | 实验、助研、仪器和样本 | 设备污染、观察反馈、月光数据 |
| 宿舍区 | 休息、关系、宿舍事件 | 共享梦境、身份模仿、消失房间 |
| 食堂与生活中心 | 饮食、超市、快递、兼职 | 欲望聚集、失物交易、补给 |
| 校医院 | 治疗、急救、专业转介 | 异常病例、污染稳定和救援 |
| 社团楼与礼堂 | 社团、排练、演出、讲座 | 群体情绪、角色壳、观众强化 |
| 体育中心 | 锻炼、比赛、社交 | 追逐、保护和体能型怪物 |
| 行政区 | 学籍、财务、奖惩、制度 | 自动归档、制度性遗忘 |
| 教职工旧住宅区 | 拜访、旧住户传闻 | 教授住宅和最终真相 |
| 湖岸与林区 | 散步、约会、摄影、观测 | 月光强区、倒影入口、巢点 |
| 后勤与地下设施 | 维修、仓储、电力、车队 | 安全通道、停电和组织路线 |

第一版重点实现宿舍、教学区、图书馆、心理学中心、生活中心、校医院、旧住宅和湖岸。其他区域可以先提供地图入口、文字功能和少量事件。

## 4. 校园人口与模拟层级

### 4.1 总人口

设定上校区约有 6000 人：

- 学生约 4000 人；
- 教师、科研、行政、医疗、安保、商业和后勤人员约 2000 人。

其余约 5800 人以人群密度、公共需求、论坛参与、消费、舆论和背景事件表现，不进行逐人完整模拟。

### 4.2 持久化 NPC

游戏维护约 200 名持久化 NPC。所有人都拥有：

- 固定身份与唯一 ID；
- 住所、学院或岗位、周日程和常去地点；
- 金钱、库存、需求、关系和行动次数；
- 学院能力、职业能力、社团与个人特质；
- 任务、伤势、情绪、秘密和异常敏感度；
- 即使没有 LLM 也能通过规则生活和执行任务。

### 4.3 LLM 深度认知层

同时保持约 20 个 LLM 深度认知槽位：

| 用途 | 建议数量 |
| --- | ---: |
| 玩家永久觉醒的 NPC | 最多 6 |
| 当前活跃任务的关键参与者 | 约 6 |
| 当夜正在行动的重要 NPC | 约 4 |
| 根据社会事件动态调度 | 约 4 |

动态 NPC 离开槽位时，将经历压缩为结构化记忆；再次激活时恢复。玩家永久觉醒的 NPC 不因离队而被叙事性降级。

### 4.4 夜相参与人口

进入夜相与是否接入 LLM 是两个独立维度。初步建议：

- 约 60 名持久化 NPC 能感知异常；
- 约 40 名具备稳定进入夜相的条件；
- 约 20～25 名在当前阶段愿意进入；
- 每夜实际行动约 6～12 名；
- LLM 和规则 NPC 都可以组队、接任务和后台战斗。

## 5. NPC 约束式生成

除导师、林默等主线不可替代角色外，暂不预设大量固定队友。NPC 按以下顺序生成：

```text
身份与生活条件
→ 学院、职业和专业方向
→ 基础属性与专业熟练度
→ 人格、价值、恐惧和执念
→ 日程、经济与物品
→ 社团和初始社会关系
→ 异常敏感度与夜相意愿
→ 秘密、身份锚点和个人矛盾
```

随机不等于无逻辑。学院主要影响专业能力，经济状况影响消费和兼职，经历影响价值与恐惧，性格影响处理方式。每个重要 NPC 至少拥有一个内在矛盾，避免成为单一标签。

## 6. 记名与觉醒

### 6.1 叙事定义

主角能够帮助少数人意识到异常、确认自身身份，并成为不容易被月光和集体记忆抹去的“被记名者”。系统层称为深度认知晋升，里世界通常称为觉醒。

### 6.2 条件

NPC 通常需要满足：

- 已进入 200 人持久模拟层；
- 与玩家发生过至少两次有意义的事件；
- 目击异常、接触失物或卷入身份事件；
- 与玩家存在足够强的信任、冲突或共同经历；
- 玩家掌握其照片、承诺、日记、重要物品等身份锚点；
- NPC 本人愿意面对异常，因此可以拒绝觉醒。

### 6.3 觉醒效果与边界

觉醒后，NPC 可以形成长期目标、主动联系和组队、提出任务、反思经历、改变关系和价值判断。觉醒不是属性强化，也不是精神控制：NPC 可以拒绝玩家、独立接任务、改变阵营，甚至因玩家突破其道德边界而决裂。

玩家在四个阶段依次获得 `1 + 1 + 2 + 2` 个永久记名名额，Demo 最多觉醒 6 人。

## 7. 时间、行动次数与疲劳

一天划分为四个宽时段，内部使用隐藏的分钟级时间处理论坛竞争与 NPC 行动先后。

| 时段 | 常见活动 |
| --- | --- |
| 上午 | 课程、考试、导师安排、固定工作 |
| 下午 | 调查、社团、兼职、购物、交友、约会 |
| 晚上 | 阅读、整理证据、社团、关系活动、准备 |
| 凌晨 | 夜相、潜入、救援、战斗；也可留在表世界 |

- 每个时段通常只能执行一个主要行动。
- 查看论坛、短对话、普通移动和普通购物不单独消耗完整时段。
- 深入调查、长时间阅读、社团活动、兼职和夜相行动消耗主要行动。
- NPC 与玩家遵守相同的地点、营业时间、物品和行动次数限制。
- 凌晨行动会增加疲劳、污染和次日迟到风险；休息是有效选择而非惩罚。

## 8. 双论坛与自主任务竞争

### 8.1 表世界论坛

面向全校，内容包括课程互助、社团招募、寻物、跑腿、交易、维修、调查、兼职、活动、求助和传闻。

- 世界中可以同时存在 40～80 个有效任务；
- 根据玩家关系、学院、地点和兴趣筛选 15～25 个重点显示；
- 所有 200 名持久化 NPC 都能阅读、发布和接受适合自己的任务。

### 8.2 里世界论坛

面向能够感知异常的人，内容包括夜间调查、护送、清除、样本回收、失心者救援和区域警戒。

- 每天保持约 20 个可见任务；
- 其中约 6～10 个为新任务，其余是延续、已锁定、临近 DDL 或失败后变化的任务；
- 任务不因玩家没有查看而暂停。

### 8.3 公平锁定

```text
OPEN
→ VIEWED
→ CONSIDERING
→ LOCKED
→ IN_PROGRESS
→ COMPLETED / FAILED / ABANDONED / EXPIRED
```

- 玩家和 NPC 在游戏时间中公平竞争。
- 第一个通过原子校验的合法接受者获得任务锁。
- 已被锁定的任务不能重复接取，但其他人可以申请协助、提供物资、追踪结果或承接后续任务。
- 接受者超时未开始、主动放弃、失去行动能力或违反条件时释放锁。
- 失败不简单删除任务，而应改变人物、地点或异常并生成后续事件。

## 9. 基础属性与统一检定

### 9.1 六项基础属性

属性范围为 1～10，5 代表普通成年人，8 代表专业优秀，10 为常人极限。

| 属性 | 战斗影响 | 表世界影响 |
| --- | --- | --- |
| 体魄 | 生命、物理威力、防御、恢复 | 搬运、破门、攀爬、锻炼 |
| 灵巧 | 命中、闪避、速度、技巧威力 | 开锁、潜行、投掷、精细操作 |
| 专注 | 专注上限、污染抵抗、技能稳定 | 阅读、实验、长时间调查 |
| 洞察 | 认知威力、弱点发现 | 观察、推理、识谎、诊断 |
| 共情 | 支援、安抚、失心者干预 | 理解情绪、修复关系、陪伴 |
| 表达 | 指挥、威慑、战斗交谈 | 说服、欺骗、表演、议价、组织 |

知识、勇敢、善良、疲劳、信任和经济压力不属于基础属性，分别由专业、人格、动态状态、关系与需求表示。

### 9.2 主要派生值

```text
最大生命 = 60 + 体魄 × 8 + 装备修正
最大专注 = 35 + 专注 × 5 + 洞察 × 2 + 技能修正
稳定阈值 = 40 + 专注 × 4 + 身份锚点 × 5 + 关系与装备修正
行动速度 = 灵巧 × 2 + 洞察 + 技能修正 + (-3～3)
物理威力 = 体魄 × 2 + 灵巧 + 武器威力
技巧威力 = 灵巧 × 2 + 洞察 + 工具修正
认知威力 = 洞察 × 2 + 专注 + 对应知识修正
支援效力 = 共情 × 2 + 表达 + 对应专业修正
防御 = 体魄 × 1.2 + 灵巧 × 0.5 + 防具与状态
```

### 9.3 统一非战斗检定

```text
检定值 = 基础属性 × 5
       + 专业熟练度 × 8
       + 物品、关系、情报和状态修正
       + 1～100 随机数

目标值 = 75 + 难度修正
```

同一个目标允许不同方案。例如开门可以使用钥匙合法开启、工具技巧开锁、撬棍暴力破门、社交说服管理员或调查备用入口；物品提供行动和修正，不直接保证成功。

## 10. 人格、关系与 NPC 决策

### 10.1 八项人格维度

每项范围 0～100：外向性、亲和性、自律性、开放性、情绪敏感、风险偏好、规则认同、利他倾向。

人格不等于道德或能力。高共情但低利他的角色可能擅长操纵；高规则认同者可能维护错误制度；高开放者愿意接受异常，也可能更容易相信未经证实的解释。

### 10.2 人格之外的角色核心

每个持久化 NPC 还应具备：

- 从安全、归属、真相、成就、自由、秩序、关怀、名誉、知识、财富中选择并排序三项核心价值；
- 1～3 条道德边界；
- 一项恐惧与一项执念；
- 休息、饮食、安全、社交、金钱、成就、好奇和承诺等动态需求；
- 愉快、恐惧、愤怒、悲伤、羞耻五项动态情绪；
- 熟悉、信任、亲密、尊重、怀疑、恐惧、欠情、冲突八项关系数值。

### 10.3 统一行动评分

```text
行动评分 = 目标推进 × 1.3
         + 需求满足 × 1.2
         + 价值符合
         + 关系影响 × 0.8
         + 承诺影响 × 1.5
         + 习惯、情绪和人格影响
         - 风险、金钱、时间和行动次数成本
         - 违法、道德冲突和机会成本
         + 小幅随机波动
```

规则系统先生成合法行动、剔除条件不符项并评分。普通 NPC 从高分项中按概率选择；LLM NPC 只收到排名前 3～5 的合法候选及相关事实，由 LLM 选择、解释或暂不行动。最终仍由规则验证和执行。

人格因此影响“愿不愿意做”，基础属性影响“能不能做好”，专业技能影响“会不会做”，需求解释“现在为什么做”，关系解释“为谁做”，LLM 负责“如何理解和表达”。

## 11. 学院能力框架

校园包含八个学院：数理、生化、天地、AI、心理、人文、医学和体育。

每名 NPC 的技能结构为：

```text
学院公共技能 × 4
+ 三条专业分支中选择一条
+ 个人特质技能 × 1
+ 社团技能 × 1
+ 关系协作技能 × 0～1
+ 失物印记技能 × 0～1
```

学院只定义能力框架，不决定性格，也不限制队伍身份。

| 学院 | 四项公共能力方向 | 三条分支方向 |
| --- | --- | --- |
| 数理 | 精确计算、规律识别、概率修正、误差控制 | 数学建模 / 物理实验 / 统计推断 |
| 生化 | 样本采集、状态识别、药剂处理、污染净化 | 生物观察 / 化学制备 / 生态与毒理 |
| 天地 | 环境观测、月相识别、路线勘察、灾害预警 | 天文 / 地质 / 大气与地理 |
| AI | 数据扫描、模式识别、设备控制、信息追踪 | 算法 / 网络安全 / 机器人与硬件 |
| 心理 | 情绪观察、专注稳定、认知分析、支持交流 | 认知 / 社会 / 发展与咨询基础 |
| 人文 | 文献考据、语言解释、叙事识别、身份见证 | 历史档案 / 文学语言 / 新闻传播 |
| 医学 | 伤势判断、急救、状态解除、恢复评估 | 临床基础 / 药理 / 公共卫生 |
| 体育 | 身体训练、保护、追击、团队协调 | 力量 / 速度技巧 / 运动康复 |

## 12. 社团系统

第一版完整实现 12 个核心社团，其余 20～30 个社团作为背景组织运行；背景社团因持续事件变得重要时可以升级为核心社团。

| 核心社团 | 表世界玩法 | 夜相能力 | 常见自主任务 |
| --- | --- | --- | --- |
| 心理学读书会 | 阅读、讨论、笔记 | 知识解析、稳定专注 | 找书、调查传闻、同伴支持 |
| 校园记者团 | 采访、写稿、调查 | 证词、识别信息矛盾 | 采访、寻人、追踪新闻 |
| 摄影社 | 拍摄、比赛、展览 | 保存异常痕迹、识破伪装 | 取景、活动拍摄、找设备 |
| 天文社 | 月相观测、设备维护 | 预测污染和夜相变化 | 观测、校准、记录月光 |
| 话剧社 | 排练、演出、角色扮演 | 伪装、模仿、身份诱导 | 招募、道具、排练冲突 |
| 辩论社 | 比赛、演讲、资料准备 | 说服、打断、瓦解自洽 | 搜集论据、公开辩论 |
| 计算机与机器人社 | 编程、比赛、维修 | 扫描、破解、设备控制 | 维修、比赛、追踪账号 |
| 志愿服务协会 | 校园服务、陪诊、公益 | 救援、护送、安抚 | 寻物、物资、照护、陪同 |
| 武术与体能社 | 训练、比赛 | 保护、反击、强制突破 | 训练、护送、比赛 |
| 户外与定向社 | 徒步、定向、探索 | 追踪、撤离、特殊入口 | 寻路、搜寻、露营准备 |
| 音乐社 | 排练、演出、节庆 | 节奏干扰、群体稳定 | 演出、招募、寻找乐器 |
| 模拟法庭与社会实践社 | 案例、规则、调研 | 规则漏洞、合法交涉 | 纠纷、违规调查、制度申诉 |

社团拥有固定活动时间、场所、入社要求、活跃度、资源和成员关系。成员分为普通成员、骨干和负责人；晋升由出勤、贡献、关系、事件表现和社团需求共同决定。社团不等待玩家，会自主招募、举办活动、发布任务、发生冲突、消耗资源和更换负责人。

## 13. 知识与角色成长

### 13.1 知识理解

```text
理论阅读 40%
+ 案例注释 30%
+ 实际应用 20%
+ 个人反思 10%
= 书籍或现象理解度
```

- 只阅读最多获得表面理论。
- 战斗不掉落书页，而是提供可记录的异常案例。
- 现象理解度 25/50/75/100 时依次开放信息、弱点、打断和特殊解法。
- 对应现象的知识增伤最高约 35%，避免知识变成单纯数值等级。

### 13.2 基础属性成长

- 体魄和灵巧主要来自锻炼、社团和实际行动。
- 专注和洞察主要来自课程、阅读、实验与调查。
- 共情和表达主要来自真实关系事件、社团组织和交流实践。
- 基础属性提升缓慢，高属性继续成长需要更大投入。
- 专业熟练度、学院分支和知识节点比基础属性更容易形成角色差异。

### 13.3 关系成长

友情、恋爱、信任、共同秘密和承诺可以形成“见证关系”，解锁协作技能和身份锚点。恋爱不由单一魅力数值决定，而由选择、尊重、兑现承诺、相处经历和价值兼容共同决定。

## 14. 物品、交易与使用行动

物品系统统一支持：

- `USE_ITEM`
- `GIVE_ITEM`
- `DROP_ITEM`
- `PICK_UP_ITEM`
- `EQUIP_ITEM`
- `UNEQUIP_ITEM`

物品提供行动、修正和后果，不保证成功。例如开锁工具允许技巧开锁，撬棍允许高噪声暴力破门，钥匙允许合法或隐蔽进入，化妆盒和证件用于身份行动，绳索用于攀爬或特殊入口，笔记本保存情报，药品处理对应伤势。

NPC 交易同时考虑需求、金钱、位置、营业时间、行动次数、关系、怀疑、性格、经济压力、保留数量、职业工具保护、物品冷却和最近成交价格。普通 NPC 平均每 2～4 天发生一次有理由的私人交易；商人、倒卖者和特定职业可以更频繁。报价、接受、拒绝和结算必须原子化。

## 15. 月光污染与夜相

白天被强烈压抑、否认、忽略和遗忘的身份、记忆、情感或承诺，会在污染月光下从人身上脱离成为“失物”；失物在夜间形成“失相”，严重受侵蚀的人则成为“失心者”。

```text
矛盾、否认和遗忘
→ 失物从原主人脱离
→ 附着于人物、物品、地点或系统
→ 污染月光使其形成失相
→ 侵蚀原主人并可能形成失心者
```

月光更像载体或镜面，而不是最终污染源。十二年前的“空白夜”、校园观测设备及睡眠与群体情绪研究共同构成长线谜团，Demo 不给出最终答案。

## 16. 敌人与双重解决

### 16.1 纯怪物

普通敌人没有完整人类人格，包括月屑、拾影兽、漏字虫、复写体、噤声蛾、梦游壳、空面者和逐光者。每种怪物拥有一到两个知识弱点和一个可观察规律。

“弗洛伊德妖”等名称只作为论坛俗称或错误归类；心理学著作不会制造怪物，只帮助玩家理解其规律。

### 16.2 失心者

失心者首先是受害者。玩家可以：

- 白天调查原因、恢复关系、提供现实支持并寻求专业帮助；
- 夜间战斗，清除污染外壳；
- 昼夜结合，以更高成本获得更完整恢复；
- 放弃介入，让其事件继续发展。

主角只是心理学学生，不能被表现为未经训练就进行临床治疗。白天玩法应是支持性沟通、现实联系、危机陪伴、证据调查和专业转介。

## 17. 战斗系统

### 17.1 基本形式

采用三人小队、无格子、无站位、按速度行动的技能指令回合制。指令包括普通攻击、战斗技能、知识技能、协作技能、使用物品、防御、交谈或呼唤、逃跑。

- 普通战斗目标时长为 3～5 分钟。
- 不设置随机遇敌和刷怪升级。
- 玩家通常可以控制队友技能，但 NPC 保留道德边界、严重恐惧、污染失控和关系反应。
- 玩家不在场的战斗使用相同人物、装备、知识和准备数据抽象结算。

### 17.2 伤害与知识

```text
物理原始伤害 = 技能基础威力 + 物理威力 × 技能倍率
物理实际伤害 = 原始伤害 × 100 / (100 + 目标防御 × 4) × 状态倍率

知识倍率 = 1 + 对应现象掌握度 × 0.0035
认知伤害 = (技能基础威力 + 认知威力 × 技能倍率)
         × 知识倍率 × 弱点倍率 × 失衡倍率 × 目标修正
```

命中知识弱点建议为 `×1.25`，失衡为 `×1.20`，强抵抗为 `×0.65`。

### 17.3 失心者与 Boss

- 战斗技能削弱污染外壳。
- 白天证据、关系、身份锚点和知识处理心结核心。
- Boss 可拥有“异常自洽度”，需要用证据和知识破坏其错误规则。
- 强制击败可以完成最低限度救援，但可能损失记忆、关系或线索。

### 17.4 污染阶段

| 污染比例 | 影响 |
| --- | --- |
| 0～29% | 无明显影响 |
| 30～59% | 专注消耗增加，出现异常感知 |
| 60～89% | 部分技能不稳定，负面记忆被放大 |
| 90～99% | 高消耗技能受限，可能拒绝危险指令 |
| 100% | 暂时失控、撤退或进入角色专属异常状态 |

## 18. 四阶段、28 天主线

### 18.1 共同节奏

每个阶段持续 7 天：

| 日程 | 功能 |
| --- | --- |
| 第 1 天 | 导师推荐读物，阶段事件出现 |
| 第 2～3 天 | 调查扩散，支线和论坛任务增长 |
| 第 4 天 | 中点变化，其他 NPC 开始改变局势 |
| 第 5 天 | 异常升级，错误选择产生代价 |
| 第 6 天 | 准备最终方案、关系和队伍 |
| 第 7 天 | 阶段 DDL 与多路线结算 |

主角是刚到镜湖校区报到的心理学学生，只通过网络与年迈、孤僻、德高望重的导师沈砚舟（暂名）交流。主角在报到时接触到无主钥匙、没有联系人的聊天记录和少了一个人的合照，因此没有完全忘记被校园抹除的学生林默（暂名）。

### 18.2 第一阶段：错名（第 1～7 天）

**读物：弗洛伊德《日常生活的心理病理学》**

- 无主钥匙、异常合照和不存在的学生形成初始谜团。
- 学籍、借阅、点名和称呼不断出现替代信息。
- 玩家从随机生成的学生、行政人员、图书馆员和社团任务中建立第一批关系。
- 阶段错误规则是“没有记录的人就不存在”。
- 第 7 天前必须保存即将被覆盖的旧学籍备份。
- 结尾恢复“林默”这个名字，但大多数人很快再次忘记。

### 18.3 第二阶段：代梦（第 8～14 天）

**读物：弗洛伊德《梦的解析》**

- 多名学生梦见同一间书房、两副眼镜和没有脸的年轻人。
- 心理学中心的研究试图用统一解释覆盖梦境差异。
- 玩家可以比较亲历者、论坛记录、照片和夜相痕迹，也可以让其他 NPC 独立调查。
- 第 14 天实验结束，原始记录将被删除或重写。
- 结尾还原年轻人发现老人自然死亡的场景，并发现林默笔记与导师邮件的习惯相似。

### 18.4 第三阶段：镜中之人（第 15～21 天）

**读物：拉康镜像阶段相关文本与原创导读**

- 校园出现角色替代、身份错位和模仿事件。
- 玩家开始意识到导师书单与现实异常存在联系。
- 调查导师最近一年是否参加过线下活动。
- 教授旧学生因尊敬、愧疚、利益或逃避共同维持“教授仍在隐居工作”的事实外观。
- 阶段错误规则是“别人认为你是谁，你就是谁”。
- 第 21 天学院将重新认证教授身份，使错误身份合法化。
- 导师撤回一条信息：“不要来找老师。来找我。”

### 18.5 第四阶段：谁在记得我（第 22～28 天）

**读物：威廉·詹姆斯《心理学原理》中关于自我与记忆的章节**

- 玩家进入旧教师住宅，确认教授一年前已经自然死亡。
- 活着的林默正在通过网络扮演教授，并逐渐相信自己就是教授。
- 教授庞大的社会身份压过联系薄弱的林默，使校园保留教授而删除学生。
- 网络导师既是教授知识和身份的延续，也是林默残余自我发出的求救。
- 第 28 夜的污染满月是林默身份被完全覆盖的最终期限。
- 玩家此前觉醒的人、建立的关系、保存的记录和未完成的任务共同决定可用结局。

## 19. 结局

- **归还姓名**：恢复林默身份并公布教授死讯；林默重新被记起，但失去大量教授知识。
- **继承教授**：允许当前人格继续继承教授身份；知识延续，林默原本的人生继续消失。
- **共同署名**：通过高知识、多人见证和关键锚点建立同时承认两段经历的新身份。
- **保留遗忘**：尊重林默放弃原身份的选择；校园恢复平静，玩家成为少数记得他的人。
- **新的导师**：玩家污染过高，教授身份转移到玩家；下一名新生收到玩家账号发出的书单。

开放尾声显示十二年前“空白夜”的合照中缺少的不止林默一人，其他地区也出现相同污染信号。

## 20. LLM 权限边界

LLM 可以：

- 从合法候选行动中选择计划并解释原因；
- 生成符合人格、关系、记忆和知识边界的对话；
- 决定相信、隐瞒、求助、协商、拒绝或背叛；
- 将规则系统生成的需求和任务表达成自然语言；
- 对已发生事件形成个人解释与后续目标。

LLM 不可以：

- 创造不存在的物品、金钱、地点、人物或证据；
- 瞬移、跳过行动次数、营业时间、装备或技能条件；
- 直接修改关系、任务状态、伤势和主线事实；
- 知道自己尚未获得的秘密；
- 声称未被规则验证的行动已经完成。

统一循环为：

```text
世界状态
→ NPC 有限观察
→ 记忆、关系、需求和目标
→ 规则生成合法候选行动
→ LLM 选择、解释或暂不行动
→ 规则再次验证
→ 执行并产生持久事件
→ 更新状态、记忆、论坛和场景
```

## 23. 当前已确定与暂缓决定

### 已确定

1. 大型虚构校园、表世界与夜相双层结构。
2. 自主 NPC 社会是第一优先级，战斗和剧情服务于这一核心。
3. Demo 为 28 天，每阶段 7 天，夜相不是每日强制活动。
4. 表世界与里世界双论坛，玩家和 NPC 公平竞争任务。
5. 除主线角色外先使用约束随机 NPC，不设置八名固定学院队友。
6. 玩家最多觉醒六名自己选择的角色，觉醒不等于控制。
7. 八学院各有四项公共能力、三条分支，另叠加特质、社团、关系与失物技能。
8. 使用六项基础属性、八维人格、多维关系和统一行动评分。
9. 战斗采用无格子、无站位、无随机卡牌的三人技能回合制。
10. 知识、生活成长、关系和战斗共同决定问题解决方式。

### 暂缓

1. 正式校名、城市名、组织名和异常术语。
2. 大量特定 NPC、固定队友和完整个人剧情。
3. 主角具体是本科生、研究生还是允许选择。
4. 恋爱系统在 Demo 中的内容深度。
5. 月光污染最终来源与“空白夜”完整真相。
6. 最终视觉风格和美术资源生产规格。

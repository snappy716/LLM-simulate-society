# UI01 公共视觉与交互规范

2026-09-11。延续已确认的亮白、清亮蓝、细暗边风格；本文件与共享主题/组件一起作为后续 UI 开发基线。

## 视觉变量

| 项目 | 当前约定 |
| --- | --- |
| 正文 | 亮白 `#f5fbff`，系统中文无衬线字体，默认 16 px |
| 重点 | 清亮蓝 `#48c2ff`；用于选中、主要操作和已完成反馈 |
| 次级文字 | `#bdcedb`；不把关键正文设为低透明度 |
| 风险 | `#ffb5bc`，搭配明确动词与确认，不只依赖颜色 |
| 页面层级 | 标题 30 px、正文 16 px、辅助说明 14 px；常驻 HUD 仍为地点 18 / 日期 13 px |
| 间距 | 同组 8 px、不同模块 12 px；系统页面外边距横向 48 / 纵向 24 px |
| 点击区 | 新系统按钮不低于 42 px 高；HUD 46×46 px，图形 30 px |
| 背景 | 模态菜单可用低饱和深蓝遮罩，让亮色文字可读；HUD 图标仍无底框 |
| 字体 | Microsoft YaHei → Hiragino Sans GB → Noto Sans CJK SC 等系统回退，不分发未授权字体 |

实现：`game/ui/themes/campus_theme.tres`、`game/scripts/ui/campus_ui_kit.gd`。现有页面自动继承共享主题；以后逐页重排时优先使用 KIT，不复制新的样式常量。

## 组件

- 主要、次要、危险按钮：常态、悬停、按下、禁用与键盘焦点可区分。危险操作有明确文字与确认步骤。
- 标签、段落、加载/空内容/暂不可用/错误/结果待确认/成功状态；状态文案必须由业务结果驱动。
- 搜索（可清空）、筛选、页签、分页；第一页/末页禁止越界操作，并说明原因。KIT 提供组件与回调，不替页面制造数据。
- 滚动容器自动跟随焦点；长文本换行。返回入口固定在内容滚动区之外。
- 确认弹窗使用统一文案和按钮尺寸，默认焦点在“取消”，关闭弹窗不执行命令。

## 输入和层级

1. 过夜过场优先接管输入，不能在其下面打开暂停菜单。
2. 确认弹窗优先于当前菜单；Esc/取消不产生存读档或新世界操作。
3. API 设置关闭后恢复之前的暂停状态和键盘焦点。
4. 系统菜单打开时暂停场景，并暂停后台社会注意力脉冲；菜单浏览不推进世界。已发出的 HTTP 请求继续完成，禁止中途重复切换世界。
5. 探索时 Esc 打开暂停菜单；手机、地图、人物等界面仍先按自己的返回逻辑逐层关闭。
6. Tab / Shift+Tab 遍历、Enter / 空格触发。读档后不恢复已销毁控件的焦点。
7. 系统菜单打开时隐藏下层 HUD，关闭后恢复；不在原四角新增常驻入口。

## 反馈与真实性

加载不显示虚构百分比。禁用按钮有原因；页面提供整体等待或空内容提示。网络异常时标记“结果尚未确认”，不自动重放有副作用的命令。列表过期使用后端 revision/token 拒绝并要求重新确认。

公共组件样例截图明确标注为样例，不代表世界发生了对应结果。未实现的音频设置、画质档位、键位重绑不放假开关。Windows 字体与输入仍须 Windows 真机验收。

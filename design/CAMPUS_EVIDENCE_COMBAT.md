# 第 10 步：现实共同经历进入卡牌战斗

基线：`6576ab8`。不增加主线、美术、调用上限或日内完整 LLM 规划。继续使用三排人物牌与共享指令费用，不引入格子或新的手牌种类。

## 玩家可感知的差异

过去知识洞察依据理解度，提供辨析规律、标记弱点、打断异常。现在白天真实互助/支持留下的共同经历，在当事人确认后，也能帮助人物对抗**对应事件**的夜间残像。

新增固定洞察「现实参照」，不依赖抽牌：

- 使用者必须已经部署且未倒下；对应现象理解至少 40。
- 必须有该事件中本人确认给使用者的关系锚点，以及自己的可靠本人陈述。原始共同经历必须是已经履行的物资互助或不同日期的实际支持，不接受空口承诺、普通礼物或别人的经历。
- 两份记录的可信度至少 0.5，歪曲不超过 0.35；仍检查当前关系意愿。过去确认不是永久许可。
- 只作用于同一人物事件投射的残像，而不是任意同种怪物；公开任务标题或全局事件账本不授予知识。
- 消耗 1 点共享指令，阻止目标下一次攻击，包括该次攻击的接触污染；不是直接伤害、胜利或现场处置。
- 全队对同一目标每战一次。已有待生效打断时不可浪费叠加；发动后换人或过回合不能重置次数。普通理解 75 的打断仍保留自己的条件与费用。
- 不改变当事人的外壳/心结/自洽度、关系、生命、专注或行动预算；实际胜利与现场处置才按原规则影响残像外壳。

没有共同经历的玩家依旧能用原卡牌、普通知识洞察或其他路线。这不是每场战斗的必做前置，也不自动把朋友招进队伍。

## 程序与隐私

`campus_evidence_insight` 校验既有来源与当前条件，生成匿名选项，并为实际发动保存私有收据。`USE_KNOWLEDGE_INSIGHT` 统一消耗指令和产生实际打断，沿用敌方行动系统，不创建替代战斗结算器。NPC 控制器选择同一合法选项和同一处理器，无新增 API 调用。

战斗投影使用服务端权威状态计算选项，再移除异常关联与证据收据。UI 只展示使用者、残像、费用、条件和效果，不泄露当事人身份、私有案例 ID、原始陈述或互助记录。不能用已经脱敏的投影作为服务端证据来源。

可选 `evidence_insight_receipts` 字段兼容旧进行中战斗；收据绑定案例、使用者、目标、锚点、两份原始声明、理解度、回合、时间与费用。存档不变量检查来源、使用标记和不可重复。已倒下角色不能使用任何知识洞察，此项同时补齐原规则的边界。

## 验收边界

专项夹具只给初始需要、物资、关系和理解阈值；请求、接受、交付、本人确认、跨时段、任务锁、道路、部署、使用洞察与敌方行动均走真实处理器。普通知识、错误来源、记录歪曲、意愿撤回、倒下、候补、费用、重复、原存档与私有投影分别验证。

规则控制器专项证明它会选同一选项并执行，不等于自然 NPC 已在长跑中频繁遇到全部前提。自然频率由七日样本另行报告，不能用受控夹具或无 API 样本冒称 LLM 涌现质量。

下一项：把白天/夜间/混合路线的已知结果和真实代价连到玩家反馈，并完成同一事件对照；其后进入第 11 步整体样本、第 12 步校园生活。主线仍不实施。
